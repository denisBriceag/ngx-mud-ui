# Chip

A compact pill that plays two distinct roles, selected with `type`:

- **`filter`** (default) — a toggle button. Clicking flips `selected` and the
  host exposes `aria-pressed`.
- **`input`** — a discrete value the user already entered. The body is static
  (no dead tab stop) and, with `removable`, a trailing close button emits
  `removed`.

## Import

```ts
import { MudChip } from 'ngx-mud-ui/chip';

@Component({
  imports: [MudChip],
  template: `
    <mud-chip selectionMode="multi" [(selected)]="active" [count]="12">Acte</mud-chip>
    <mud-chip type="input" removable (removed)="drop(tag)">{{ tag }}</mud-chip>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## Filter modes

`mono` is radio-like: the chip only flips color, and keeping the group exclusive
is the consumer's job — react to `selectedChange` and clear the others. `multi`
is checkbox-like and renders a leading check automatically while selected.

## Usage tips

- **`selected` is a `model()`** — bind it two-way with `[(selected)]`, or listen
  to `selectedChange` and drive it yourself. It is ignored for `type="input"`.
- **Mono-exclusivity is not built in.** With `selectionMode="mono"` the chip
  still toggles itself independently; only one chip appearing active is
  something you enforce in the parent, as the Filter modes example shows.
- **`removable` only applies to `type="input"`.** Setting it on a filter chip
  renders nothing — the remove button requires both.
- **Rename the remove button with `removeLabel`.** It is a function that gets
  the chip's `label` and returns the button's accessible name, such as
  `removeLabel = (name: string) => 'Elimină ' + name`, bound with `[removeLabel]="removeLabel"`. Unset, the `chip.remove` label
  applies (English `"Remove Ana Popescu"`), so a language pack from
  `provideMudLabels` translates it. See the [Localization guide](?path=/docs/foundations-localization--docs).
- **`label` is ARIA-only.** It sets `aria-label` on the chip and enriches the
  remove button's name — it does not render. Visible text belongs in the default
  content.
- **`count` renders only for finite numbers**, so leaving it `undefined` hides
  the badge while `[count]="0"` shows a zero.
- **`disabled` blocks both interactions** — toggling and removing — and disables
  the underlying native buttons.
