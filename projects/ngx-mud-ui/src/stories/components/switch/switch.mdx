# Switch

An instant on/off toggle. A native `<input type="checkbox" role="switch">` — the
official accessibility pattern — drives a styled track and thumb, and the label
toggles on click.

## Import

```ts
import { MudSwitch } from 'ngx-mud-ui/switch';
import { MudLabel } from 'ngx-mud-ui/label';

@Component({
  imports: [MudSwitch, MudLabel],
  template: `
    <mud-switch [formControl]="notifications">
      <mud-label>Notificări prin e-mail</mud-label>
    </mud-switch>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

### Label

The switch renders no message text of its own. Project a `<mud-label>` for
the visible label beside the track — without one, fall back to `aria-label`
or `aria-labelledby` for the accessible name.

## Usage tips

- **A switch takes effect immediately.** If the change only applies after a
  Save button, use a checkbox — the switch's affordance promises instant
  application.
- **It is deliberately minimal**, matching the official switch: one size, and no
  invalid, readonly or supporting-text states. Attach an external message with
  `aria-describedby` when you need one.
- **It works with both forms systems**: signal forms via the `FormCheckboxControl`
  contract, reactive and template-driven forms via `ControlValueAccessor`, or
  standalone with `[(checked)]`.
- **Use `aria-label` only when no `mud-label` is projected**; with both set
  the accessible name silently replaces the visible one.
