# Phone input

Phone entry with a country dial-code prefix and a per-country format mask. The
form value is canonical **E.164** (`+37362123456`); the masked national segment
you see is only a rendering of it. Works standalone via `[(value)]`, with
reactive and template-driven forms via `ControlValueAccessor`, and with signal
forms.

## Import

```ts
import { MudPhoneInput } from 'ngx-mud-ui/phone-input';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';

@Component({
  imports: [MudPhoneInput, MudLabel, MudInlineMessage],
  template: `
    <mud-phone-input [formControl]="phone" required>
      <mud-label>Telefon</mud-label>
      @if (phone.touched && phone.invalid) {
        <mud-inline-message variant="error">Introduceți un număr complet.</mud-inline-message>
      }
    </mud-phone-input>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## States

Besides `disabled` and `readonly`, the field has a `loading` state for when its
number is still being fetched, for example from the person's profile. While
`loading` is on, a spinner shows inside the field, nothing can be typed or
cleared, the country list can't open (an open one closes), and screen readers
hear the field as busy. It works like `loading` on the text and number fields.

```html
<mud-phone-input [value]="phone()" [loading]="profileLoading()">
  <mud-label>Telefon</mud-label>
</mud-phone-input>
```

### Label and messages

The field renders no message text of its own. Project a `<mud-label>` for
the visible label and any number of `<mud-inline-message>` elements for
assistive text — *you* decide when they render:

- Messages land in a field-owned `role="alert"` region wired into
  `aria-describedby` on the tel input.
- Inside a field, `mud-inline-message` is always the small size — its
  `size` input is ignored.
- The field's `invalid` input drives the red border and `aria-invalid`;
  with signal forms it is bound automatically, with reactive forms bind
  `[invalid]="ctrl.invalid && ctrl.touched"`.

## Usage tips

- **The value is always E.164, or empty.** A bare dial code is not a phone
  number, so an empty field publishes `''` rather than `'+373'` — your
  `required` validator works as written.
- **`country` is two-way and self-correcting.** Writing a `value` whose dial
  code belongs to another country in the list moves `country` to it, so loading
  a stored `+40…` number selects Romania without you wiring anything. Changing
  `country` keeps the digits and swaps the dial code.
- **An unknown `country` warns and falls back to Moldova** rather than
  rendering an empty prefix.
- **Digits are clamped to the country maximum** as you type; the mask cannot
  overflow.
- **`changed` reports completeness**, meaning the national digit count sits in
  that country's `minDigits..maxDigits` window. Length varies per country (and
  is a range for Germany, Italy and Bulgaria), so a single length validator
  cannot express it — read it from the event instead.
- **Editing mid-number keeps your caret.** The caret is re-anchored to the digit
  it followed after each re-mask, which is a deliberate improvement over the
  reference implementation's jump-to-end behaviour.
- **In `international` mode the search field owns the keyboard.** Opening moves
  focus into it (the trigger keeps `aria-activedescendant` semantics on the
  search input), arrows and Home/End walk the *filtered* rows, Enter selects and
  Escape closes — both returning focus to the trigger. This differs from
  `mud-select-input`, which keeps focus on its trigger; the search field is what
  forces the difference.
- **`countries` both narrows and extends the list.** Entries are either an ISO
  code from the built-in table (`'RO'`) or a whole `MudPhoneCountry` object,
  which is how you add a country the curated set does not carry:

  ```ts
  const POLAND: MudPhoneCountry = {
    iso: 'PL', dialCode: '+48', name: 'Poland',
    mask: 'XXX XXX XXX', minDigits: 9, maxDigits: 9,
    flag: 'data:image/svg+xml,…', // optional; the row renders without one
    aliases: ['Polska'],          // optional extra search terms
  };

  <mud-phone-input mode="international" [countries]="['MD', 'RO', POLAND]" />
  ```

  For a form with several phone fields, configure the list once instead:

  ```ts
  bootstrapApplication(App, {
    providers: [provideMudPhoneCountries(['MD', 'RO', POLAND])],
  });
  ```

  Precedence is field input → provider → the curated table, so one field can
  still opt out with its own `countries`.

  A supplied country is selectable via `country`, is matched by dial-code
  inference, and formats with its own mask. Unknown ISO codes are skipped with
  a dev warning, and a malformed object (a mask whose `X` count disagrees with
  `maxDigits`, a bad dial code, inverted digit bounds) warns but is still
  offered — run `validateCountry()` yourself if you want to check ahead of time.
- **The default list is the official curated diaspora set** (15 entries,
  Moldova first) — it is upstream's curation for the eGov audience, not a
  technical limit. Import `MUD_PHONE_COUNTRIES` if you need the dial codes,
  masks or digit windows yourself, and extend via `countries` as above.
- **Country names are localised by the platform, not by data we ship.** The
  visible name comes from `Intl.DisplayNames` keyed on the ISO code, in the
  format locale (override per field with `locale`; otherwise
  `provideMudFormatLocale`, then `LOCALE_ID`). So the list reads
  "Germania" in a Romanian app and "Германия" in a Russian one without any
  per-language table. `MudPhoneCountry.name` is only the English fallback for
  runtimes without `Intl.DisplayNames` — and it stays searchable, so typing the
  English name works in any locale. Add regional spellings via `aliases`.
- **The country button's name is a function of the country.** `countryLabel`
  takes the country name and dial code and returns the accessible name, such as
  `countryLabel = (name: string, code: string) => 'Țara: ' + name + ' ' + code`, bound with `[countryLabel]="countryLabel"`. Unset, the
  `phoneInput.country` label applies (English "Country: Moldova +373"). The other
  texts (`clearLabel`, `countryListLabel`, `countrySearchLabel`, `countryEmptyText`) are optional
  overrides of the same namespace. The country list has its own name,
  `countryListLabel` (English "Country"); it doesn't change with the selected country.
- **Use `aria-label` only when no `mud-label` is projected**; with both set
  the accessible name silently replaces the visible one.
