# Spinner

An indeterminate loading indicator for work with no measurable progress. It
renders as a status region so assistive tech is told that something is loading.

## Import

```ts
import { MudSpinner } from 'ngx-mud-ui/spinner';

@Component({
  imports: [MudSpinner],
  template: `
    <mud-spinner />
    <mud-spinner size="small" variant="light-on-color" aria-label="Se încarcă" />
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## Usage tips

- **Always set a localized `aria-label`.** It defaults to the English
  `'Loading'`, which is a safety net rather than a choice — the text is rendered
  visually hidden inside the status region and read aloud.
- **`variant="light-on-color"` is for saturated backgrounds**, where the default
  brand spinner loses contrast.
- **Don't stack a spinner on a loading button.** `mudButton` has its own
  `loading` state with the matching accessibility contract.
- **Use it only for indeterminate waits.** When you know how much work is left,
  a progress indicator tells the user far more.
