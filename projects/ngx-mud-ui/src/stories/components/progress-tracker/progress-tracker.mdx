# Progress tracker

A multi-step flow built on the CDK stepper. `mud-progress-tracker` owns the rail
and the selection; each `mud-step` contributes a header and its content.
`mud-step-indicator` is the separate read-only variant that lists the stages of
a process without navigation.

## Import

```ts
import { MudProgressTracker, MudStep } from 'ngx-mud-ui/progress-tracker';

@Component({
  imports: [MudProgressTracker, MudStep],
  template: `
    <mud-progress-tracker [linear]="true">
      <mud-step label="Identity" [stepControl]="identityForm">…</mud-step>
      <mud-step label="Review">…</mud-step>
    </mud-progress-tracker>
  `,
})
export class Demo {}
```

The design-system stylesheet must be loaded once in your app:

```scss
@use 'ngx-mud-ui/styles/main';
```

## Usage tips

- **`linear` needs a `stepControl` to be meaningful.** Without one the tracker
  has nothing to validate, so forward navigation is never blocked.
- **`stepClick` is cancellable.** It fires before the click selects a step, and
  calling `preventDefault()` on the event keeps the selection unchanged — the
  hook for "you have unsaved changes" prompts.
- **`compact` also switches on automatically** for horizontal trackers narrower
  than 600px. Setting it forces the number-less dot rail at every width; labels
  stay hidden visually but are still announced.
- **The step indicator is not the tracker.** `mud-step-indicator` is a read-only
  summary of a process with no selection and no content panes — use it on
  landing and information pages, not in a wizard.
