# Input

The single-line text field: label, helper text, error region, optional leading
and trailing icons, and a clear button. Works standalone via `[(value)]`, with
reactive and template-driven forms, and with signal forms.

## Import

```ts
import { MudInput, MudInputError, MudInputHelper, MudInputLabel } from 'ngx-mud-ui/input';

@Component({
  imports: [MudInput],
  template: `<mud-input label="IDNP" required [formControl]="idnp" [maxLength]="13" />`,
})
export class Demo {}
```

The design-system stylesheet must be loaded once in your app:

```scss
@use 'ngx-mud-ui/styles/main';
```

## Usage tips

- **`errorText` replaces `helperText`** while invalid — both can stay set, and
  only one renders.
- **`invalid` drives visuals, the text supplies the message.** Setting
  `errorText` alone renders nothing until `invalid` is true; signal forms bind
  `invalid` and `errors` automatically.
- **`aria-describedby` is for messages rendered outside the field.** The field
  already wires its own helper and error ids; to use only your own, leave
  `helperText` / `errorText` unset and don't project the slots.
- **`pattern` accepts a string, a RegExp, or the `RegExp[]` signal forms push.**
  It is normalised internally, and only the first expression reaches the native
  `pattern` attribute.
- **`clearable` is suppressed** while the field is disabled, read-only or
  loading, so the affordance never appears on a field the user cannot edit.
- **Localize `clearLabel`** — it defaults to the English `'Clear field'` and is
  the clear button's accessible name.
