# Search input

A text field specialised for queries: a leading search glyph, a clear
affordance, an optional integrated submit button, and a `searched` output that
fires on Enter.

## Import

```ts
import { MudSearchInput } from 'ngx-mud-ui/search-input';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';

@Component({
  imports: [MudSearchInput, MudLabel, MudInlineMessage],
  template: `
    <mud-search-input shape="circular" placeholder="Caută servicii" (searched)="find($event)">
      <mud-label>Căutare</mud-label>
    </mud-search-input>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

### Label and messages

The field renders no message text of its own. Project a `<mud-label>` for
the visible label and any number of `<mud-inline-message>` elements for
assistive text — *you* decide when they render:

- Messages land in a field-owned `role="alert"` region wired into
  `aria-describedby`; toggling one on announces it to screen readers.
- Inside a field, `mud-inline-message` is always the small size — its
  `size` input is ignored.
- The field's `invalid` input drives the red border and `aria-invalid`;
  with signal forms it is bound automatically, with reactive forms bind
  `[invalid]="ctrl.invalid && ctrl.touched"`.

## Usage tips

- **`searched` is the one to bind**, not `valueChange`. It fires on Enter and on
  the submit button with the current query, which is the "user asked for
  results" moment; `value` changes on every keystroke.
- **`clearable` is on by default here**, unlike the plain input. Clearing emits
  `cleared` — reset your results there rather than debouncing an empty query.
- **`withButton` is for prominent search surfaces**, such as a portal landing
  page. Inline filters usually read better without it, since Enter already
  submits.
- **`shape="circular"` is the hero-search silhouette.** Keep `rectangular` when
  the field sits in a form beside other inputs, so the rhythm matches.
- **Label it even when the placeholder seems enough.** A placeholder disappears
  on focus and is not a substitute for a `<mud-label>` or `aria-label`.
- **Localize `submitLabel` and `clearLabel`** — they default to the English
  `'Search'` and `'Clear'` and are the accessible names of those two buttons.
