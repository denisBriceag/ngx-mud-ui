# Link

An attribute directive that styles a native `<a>`. The anchor keeps its own
semantics, so `href`, `target`, `routerLink` and event bindings all work
unchanged.

## Import

```ts
import { MudLink } from 'ngx-mud-ui/link';

@Component({
  imports: [MudLink],
  template: `
    <a mudLink href="/services">Services</a>
    <a mudLink="strict" size="small" underline="none" href="/terms">Terms</a>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## Usage tips

- **External links are handled for you.** With `external` left on (the default),
  an anchor with `target="_blank"` and no trailing icon gets the external-link
  glyph after its label. Set `external="false"` to suppress it.
- **`underline="none"` needs another affordance.** Removing the underline leaves
  color as the only signal, which fails for colorblind readers unless the link
  sits somewhere unmistakably interactive, like a nav bar.
- **`touchTarget="auto"` expands the hit area only where it is safe** — inline
  links in a paragraph keep their natural box so the expansion doesn't overlap
  neighbouring text.
- **`disabled` on an anchor is advisory.** As with buttons, there is no native
  disabled state for links; the directive maps it to `aria-disabled` and removes
  the tab stop rather than removing the `href`.
- **Use a button, not a link, for actions.** A link navigates; anything that
  mutates state belongs on `mudButton`.
