# ngx-egov-ui

Angular v22 component library implementing the **eGov Moldova** design system —
icons, styles, and typography, packaged for reuse across eGov products.

## What's inside

- **Icons** — 156 tree-shakeable SVG icons rendered by a single `<egov-icon>`
  component, shipped from the `ngx-egov-ui/icons` entry point.
- **Styles** — the design-system SCSS (abstracts, themes, utilities) shipped
  from `ngx-egov-ui/styles`, with light/dark theming via CSS custom properties.
- **Typography** — the **Onest** font, bundled with the styles.

## Icons quick start

Register the icons you use once (only registered icons are bundled), then use
`<egov-icon>` anywhere:

```ts
// bootstrap
import { provideEgovIcons, alarm, arrowLeft } from 'ngx-egov-ui/icons';

bootstrapApplication(App, {
  providers: [provideEgovIcons([alarm, arrowLeft])],
});
```

```ts
// component
import { EgovIconComponent } from 'ngx-egov-ui/icons';

@Component({
  imports: [EgovIconComponent],
  template: `<egov-icon name="alarm" variant="outlined" scale="24" />`,
})
export class Demo {}
```

Full guide: see the `ngx-egov-ui/icons` README. Icons default to
`variant="outlined"`, `scale="24"`, recolor via CSS `color`, and expose an
`aria-label` for semantic (non-decorative) use.
