# Getting started

Angular components for **MUD**, the Moldova Unified Design system.

> **Unofficial.** `ngx-mud-ui` is an independent project, not made or endorsed by eGov Moldova,
> and not meant for production. It is inspired by the official
> [`@egov-moldova/mud`](https://www.npmjs.com/package/@egov-moldova/mud) package and the
> [MUD documentation](https://mud.dev.egov.md/).

## 1. Install

Requires Angular 22.2 or later. In your application, run:

```bash
ng add ngx-mud-ui
```

The schematic installs the peer dependencies, registers the stylesheets in `angular.json` and
sets the Onest font on `body`. It asks whether to include the dark theme (`--darkMode` skips the
prompt); in a multi-app workspace, pass `--project <name>`.

## 2. Use a component

Every component is standalone. Import it from its entry point and add it to `imports`:

```ts
import { Component } from '@angular/core';
import { MudButton } from 'ngx-mud-ui/button';

@Component({
  selector: 'app-root',
  imports: [MudButton],
  template: `<button type="button" mudButton>Continue</button>`,
})
export class App {}
```

## 3. Register icons (optional)

Only the icons you register reach your bundle:

```ts
import { provideMudIcons, alarm, arrowLeft } from 'ngx-mud-ui/icons';

bootstrapApplication(App, {
  providers: [provideMudIcons([alarm, arrowLeft])],
});
```

Then render them with `<mud-icon name="alarm" />`. See **Components → Icon** for the full set.

<details>
  <summary><strong>Manual setup (without <code>ng add</code>)</strong></summary>

Install the package and its peer dependency:

```bash
npm install ngx-mud-ui @angular/cdk
```

Add the stylesheets to the `build` target's `styles` in `angular.json` (and to `test` if it
uses Karma), before your own. Add `ngx-mud-ui/prebuilt/mud-dark.css` too if you want the dark
theme.

```json
"styles": [
  "@angular/cdk/overlay-prebuilt.css",
  "ngx-mud-ui/prebuilt/mud.css",
  "src/styles.scss"
]
```

Set the page font in your global stylesheet:

```scss
body {
  font-family: var(--mud-font-family-base);
  font-size: 1rem;
}
```

</details>
