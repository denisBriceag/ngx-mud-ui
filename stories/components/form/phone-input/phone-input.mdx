# Phone input

A phone number field that formats the number as you type and returns it in international (E.164)
form. Moldova by default, with an optional list of countries. It works on its own with `[(value)]`,
with reactive and template-driven forms, and with signal forms.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudPhoneInput } from 'ngx-mud-ui/phone-input';
```

## Basic

`value` is always E.164 (`+37362123456`), or `''` when no digits are entered, so a `required`
validator works as usual. The number is formatted with the country's mask, and digits beyond the
country's maximum are refused. The caret stays in place when you edit mid-number.

`changed` fires on blur with `{ value, country, complete }`. Number lengths differ per country (some
allow a range), so read `complete` instead of writing a length validator.

## Choosing a country

`mode="local"` (default) shows a fixed dial code. `mode="international"` adds a button that opens a
searchable list of countries. `country` (an ISO code such as `'MD'`) is two-way bindable and follows
the number: a stored `+40…` number selects Romania. Changing the country keeps the digits.

Country names come from the browser (`Intl.DisplayNames`) in the field's `locale`, or the
[formatting locale](?path=/docs/foundations-localization--docs), so they read "Germania" in a
Romanian app. The English name stays searchable in any language.

## Your own country list

The default list has 15 countries, Moldova first. `countries` narrows it with ISO codes (`'RO'`) or
extends it with `MudPhoneCountry` objects. For every phone field in the app, use
`provideMudPhoneCountries([...])` instead; a field's own `countries` still wins. Unknown codes are
skipped and malformed countries warn in development; `validateCountry()` checks one yourself.

## States

`variant`, `invalid`, `required`, `readonly` and `disabled` work as in a
[Text input](?path=/docs/components-form-text-input--docs). `loading`, for example while the number
loads from the user's profile, shows a spinner, blocks editing and closes the country list.
`clearable` adds a × button. `size` is `md` (default) or `lg`.

## Accessibility

- The country button is named "Country: Moldova +373", or by your `countryLabel(name, dialCode)`
  function. The list, its search field and the "no results" text use `countryListLabel`,
  `countrySearchLabel` and `countryEmptyText`; the clear button uses `clearLabel`. All are
  translatable.
- In the country list, focus moves to the search field: arrows, <kbd>Home</kbd> and <kbd>End</kbd>
  move through the matches, <kbd>Enter</kbd> selects and <kbd>Esc</kbd> closes, returning focus to
  the button.
- Messages sit in a `role="alert"` region linked to the number input. Call `focus()` to focus it.

### Functions and constants

- `provideMudPhoneCountries(countries)`: the country list for every phone field.
- `MUD_PHONE_COUNTRIES`: the built-in countries; `MUD_PHONE_DEFAULT_ISO`: `'MD'`; `MUD_PHONE_FLAGS`:
  their flag images.
- `findCountry(iso)`, `findCountryByDialCode(...)`, `validateCountry(country)`.

### Types

- `MudPhoneCountry`: `{ iso; dialCode; name; mask; minDigits; maxDigits; aliases?; flag? }`. In
  `mask`, `X` is a digit and anything else is shown as is.
- `MudPhoneInputChange`: `{ value: string; country: string; complete: boolean }`
- `MudPhoneInputMode`: `'local' | 'international'`
- `MudPhoneInputSize`: `'md' | 'lg'`
- `MudPhoneInputVariant`: `'default' | 'warning' | 'destructive' | 'success'`
