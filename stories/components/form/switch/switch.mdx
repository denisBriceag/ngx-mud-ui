# Switch

An on/off toggle that takes effect immediately. If the change only applies after the user presses
Save, use a [Checkbox](?path=/docs/components-form-checkbox--docs) instead.

```ts
import { MudLabel } from 'ngx-mud-ui/label';
import { MudSwitch } from 'ngx-mud-ui/switch';
```

## Basic

Put a `<mud-label>` inside; clicking it toggles the switch. `checked` is two-way bindable. The switch
has one size and no invalid, read-only or help-text states, like the official design. For a message,
point `aria-describedby` at your own element.

<Canvas of={SwitchStories.Basic} />

## Reactive forms

Bind `formControl`, `formControlName` or `ngModel`; the value is a `boolean`.

<Canvas of={SwitchStories.ReactiveForms} />

## Signal forms

Bind `[formField]`: the value and `disabled` follow the field.

<Canvas of={SwitchStories.SignalForms} />

## Accessibility

The switch is a native checkbox with `role="switch"`, so <kbd>Space</kbd> toggles it and screen
readers announce "on" or "off". Use `aria-label` or `aria-labelledby` only when there's no
`<mud-label>`.
