# Segmented control

A row of connected buttons for switching between a few views, such as list and grid. For choosing
data in a form, or more than about five options, use a [Radio](?path=/docs/components-form-radio--docs)
group or a [Select](?path=/docs/components-form-select-input--docs).

```ts
import { MudSegment, MudSegmentedControl } from 'ngx-mud-ui/segmented-control';
```

## Basic

Put a `<button mud-segment [value]>` per option inside `<mud-segmented-control>`. `value` is
two-way bindable, and `selectionChange` emits `{ value, segment }`. The control has no visible
label, so always set `aria-label` or `aria-labelledby`. A segment can be `disabled` on its own.

<Canvas of={SegmentedControlStories.Basic} />

## Sizes, icons and full width

`size` is `md` (default) or `sm`. A segment can start with a `<mud-icon>` (24px) or `<svg>`.
`disabled` on the control disables every segment. `fullWidth` stretches the control and shares the
width between segments, for phones.

<Canvas of={SegmentedControlStories.Sizes} />

## Long labels

A label that doesn't fit is cut to one line with "…"; screen readers still get the full text. No
tooltip is added for you: add a `mudTooltip` to the segment if you want one.

<Canvas of={SegmentedControlStories.LongLabels} />

## Reactive forms

Bind `formControl`, `formControlName` or `ngModel`; the value and disabled state follow. The
control has no error style or message area, since it switches views rather than collecting data.

<Canvas of={SegmentedControlStories.ReactiveForms} />

## Signal forms

Bind `[formField]`: the value and `disabled` follow the field.

<Canvas of={SegmentedControlStories.SignalForms} />

## Accessibility

The control is a `radiogroup` and each segment a `radio` with `aria-checked`. <kbd>Tab</kbd> enters
at the selected segment; <kbd>←</kbd> <kbd>→</kbd> (or <kbd>↑</kbd> <kbd>↓</kbd>), <kbd>Home</kbd>
and <kbd>End</kbd> move to another segment and select it.
