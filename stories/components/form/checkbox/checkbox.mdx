# Checkbox

A checkbox with a label and optional messages. It works on its own with `[(checked)]`, with reactive
and template-driven forms, and with signal forms.

```ts
import { MudCheckbox } from 'ngx-mud-ui/checkbox';
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
```

## Basic

Put a `<mud-label>` inside for the visible label, and any `<mud-inline-message>` for help or errors.
The checkbox links them to the input for screen readers. `checked` is two-way bindable.

<Canvas of={CheckboxStories.Basic} />

## States

- `indeterminate` shows a dash, for a partly checked group. It's yours to manage: a click doesn't
  clear it.
- `invalid` shows the error style and sets `aria-invalid`. The checkbox shows no message by itself;
  add a `<mud-inline-message variant="error">` when you want one.
- `readonly` keeps the checkbox focusable but unchangeable; `disabled` takes it out entirely.
- `required` adds a red asterisk. `size` is `medium` (24px, default) or `small` (20px).

<Canvas of={CheckboxStories.States} />

## Reactive forms

Bind `formControl` or `formControlName`. Bind `invalid` yourself, usually
`ctrl.invalid && ctrl.touched`, and show the error message under the same condition.

<Canvas of={CheckboxStories.ReactiveForms} />

## Signal forms

Bind `[formField]`: the value, `disabled` and `invalid` follow the field. When the message appears
is still up to you; here it waits until the field is touched.

<Canvas of={CheckboxStories.SignalForms} />

## Select all

A parent checkbox whose state comes from its children: checked when all are, indeterminate when
some are.

<Canvas of={CheckboxStories.SelectAll} />

## Accessibility

- It's a native checkbox, so <kbd>Space</kbd> toggles it.
- Messages sit in a `role="alert"` region linked with `aria-describedby`, so showing one announces
  it.
- Use `aria-label` only when there's no `<mud-label>`; it would replace the visible name.
