# Search input

A search field with a search icon, a clear button and an optional submit button. It works on its
own, with reactive and template-driven forms, and with signal forms.

```ts
import { MudLabel } from 'ngx-mud-ui/label';
import { MudSearchInput } from 'ngx-mud-ui/search-input';
```

## Basic

React to `searched`: it fires on <kbd>Enter</kbd> or the submit button, with the query. `value`
(two-way bindable) changes on every keystroke. `clearable` is on by default; clearing emits
`cleared`, the place to reset your results. Label the field even if the placeholder seems enough.

<Canvas of={SearchInputStories.Basic} />

## Shapes, sizes and the submit button

`shape` is `rectangular` (default, for forms) or `circular` (for a prominent search, such as on a
landing page). `size` is `md` (40px, default) or `lg` (48px). `withButton` adds a submit button
at the end.

<Canvas of={SearchInputStories.Shapes} />

## Icons and states

An icon with `icon-start` replaces the search icon; one with `icon-end` adds a trailing icon and
replaces the clear button. While `loading`, a spinner takes the trailing place. `invalid`,
`readonly` and `disabled` work as in a [Text input](?path=/docs/components-form-text-input--docs).

<Canvas of={SearchInputStories.States} />

## Reactive forms

Bind `formControl` or `formControlName`, and bind `invalid` yourself, usually
`ctrl.touched && ctrl.invalid`. The value is the query string.

<Canvas of={SearchInputStories.ReactiveForms} />

## Signal forms

Bind `[formField]`: the value, `disabled`, `minLength` and `invalid` follow the field. Here the list
filters while the query is valid.

<Canvas of={SearchInputStories.SignalForms} />

## Accessibility

- The clear and submit buttons are named "Clear" and "Search" (translatable), or by `clearLabel`
  and `submitLabel`.
- Messages sit in a `role="alert"` region linked with `aria-describedby`.
- Use `aria-label` only when there's no `<mud-label>`. Call `focus()` to focus the field.

## API

Selector: `mud-search-input`

<ArgTypes of={SearchInputStories} />

Method: `focus(options?)`. Content slots: `mud-label`, `[icon-start]`, `[icon-end]` and
`mud-inline-message`.

### Types

- `MudSearchInputVariant`: `'default' | 'destructive'`
- `MudSearchInputSize`: `'md' | 'lg'`
- `MudSearchInputShape`: `'rectangular' | 'circular'`
