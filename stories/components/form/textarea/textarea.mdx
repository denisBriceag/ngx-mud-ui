# Textarea

A multi-line text field with a label, messages and an optional character counter. It works on its
own with `[(value)]`, with reactive and template-driven forms, and with signal forms.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudTextarea } from 'ngx-mud-ui/textarea';
```

## Basic and counter

Put a `<mud-label>` and any `<mud-inline-message>` inside, as in a
[Text input](?path=/docs/components-form-text-input--docs). With `maxLength` set, a `n / max`
counter shows (turn it off with `[showCounter]="false"`). The visible counter isn't useful to screen
readers, so give it a sentence with `counterLabel`. `maxLength` is a hard limit; for a soft one,
validate in the form instead.

`rows` (default 4) is the starting height. `resize` is `vertical` (default) or `none`; horizontal
resizing is never allowed.

## Variants and states

The same as a text input: `variant` (`default`, `warning`, `success`, `destructive`), `invalid`,
`required`, `readonly` and `disabled`. `size` is `md` (120px tall at least, default) or
`lg` (150px).

## Forms

Bind `formControl` and bind `invalid` yourself, or bind `[formField]` and let the field drive
`invalid`, `required` and `maxLength`.

<Canvas of={TextareaStories.Forms} />

## Accessibility

Messages and the counter are linked with `aria-describedby`; messages sit in a `role="alert"` region,
so showing an error announces it. Use `aria-label` only when there's no `<mud-label>`. Call `focus()`
to focus the textarea.

## API

Selector: `mud-textarea`

<ArgTypes of={TextareaStories} />

Method: `focus(options?)`. Content slots: `mud-label` and `mud-inline-message`.

### Types

- `MudTextareaVariant`: `'default' | 'warning' | 'destructive' | 'success'`
- `MudTextareaSize`: `'md' | 'lg'`
- `MudTextareaResize`: `'vertical' | 'none'`
