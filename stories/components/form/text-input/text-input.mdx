# Text input

A single-line text field with a label, optional icons and messages. It works on its own with
`[(value)]`, with reactive and template-driven forms, and with signal forms.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudTextInput } from 'ngx-mud-ui/text-input';
```

## Basic

Put a `<mud-label>` inside for the label and any `<mud-inline-message>` for help or errors; the field
links them to the input. Inside a field, messages always use the small size. `value` is two-way
bindable. Native attributes such as `type`, `autocomplete`, `inputMode`, `minLength`, `maxLength`
and `pattern` are inputs.

<Canvas of={TextInputStories.Basic} />

## Variants and states

- `variant` is `default`, `warning`, `success` or `destructive`. `invalid` forces `destructive` and
  sets `aria-invalid`.
- `required` adds a red asterisk; `readonly` keeps the value focusable and copyable; `disabled`
  turns it off.
- `loading` shows a spinner, blocks input and sets `aria-busy`.
- `size` is `md` (40px, default) or `lg` (48px).

The field shows no message by itself: add a `<mud-inline-message>` when you want one.

## Icons and clear button

Put a 20px icon at the start with `icon-start` or at the end with `icon-end`. `clearable` shows a ×
button while the field has a value; it's hidden while the field is disabled, read-only or loading.
The button is named "Clear field" (translatable), or by `clearLabel`.

## Reactive forms

Bind `formControl` or `formControlName`, and bind `invalid` yourself, usually
`ctrl.invalid && ctrl.touched`. Show a message per error, as here.

## Signal forms

Bind `[formField]`: the value, `disabled`, `required`, `pattern` and `invalid` follow the field. This
example shows the first failing validator's message once the field is touched.

## Accessibility

- Messages sit in a `role="alert"` region linked with `aria-describedby`, so showing an error
  announces it.
- `aria-describedby` on the field adds ids of messages you render elsewhere.
- Use `aria-label` only when there's no `<mud-label>`. A placeholder is not a label.
- Call `focus()` to focus the input.

## API

Selector: `mud-text-input`

<ArgTypes of={TextInputStories} />

Method: `focus(options?)`. Content slots: `mud-label`, `[icon-start]`, `[icon-end]` and
`mud-inline-message`.

### Types

- `MudTextInputVariant`: `'default' | 'warning' | 'destructive' | 'success'`
- `MudTextInputSize`: `'md' | 'lg'`
- `MudTextInputType`: `'text' | 'email' | 'password' | 'tel' | 'url' | 'search'`
