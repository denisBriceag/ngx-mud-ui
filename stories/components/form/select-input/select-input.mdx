# Select

A field that opens a list to pick one option, with optional search, groups and server-side results.
It works on its own with `[(value)]`, with reactive and template-driven forms, and with signal forms.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudSelectInput } from 'ngx-mud-ui/select-input';
import type { MudSelectItem, MudSelectOption } from 'ngx-mud-ui/select-input';
```

## Basic

Options are data, not elements: pass an array of `{ value, label, disabled? }` to `options`. `value`
is two-way bindable and keeps its type, so options can carry numbers or objects. Put a `<mud-label>`
and any `<mud-inline-message>` inside, as in a
[Text input](?path=/docs/components-form-text-input--docs). `placeholder` shows while nothing is
selected. `open` is two-way bindable too.

<Canvas of={SelectInputStories.Basic} />

## States and start icon

`invalid`, `required` and `disabled` work as in a text input; `readonly` keeps the field focusable
but the list closed. `size` is `md` (40px, default) or `lg` (48px). With no options, the list
shows "No options" (`emptyText`).

An element with `icon-start` shows before the text; mark it `aria-hidden="true"`.

## Search and groups

`searchable` turns the field into a text input that filters the list. Matching ignores case and
diacritics (`balti` finds Bălți) and looks at labels only. When nothing matches, the list shows "No
results" (`noResultsText`). Closing the list clears the text, so the field shows the selected label
again. `query` is two-way bindable; pass `filterWith` (a function of option and query) to match
differently. `mudSelectDefaultFilter` is exported if you want to wrap it.

Put `{ label, options }` objects in `options` for a heading above a run of options, one level deep.
A group with no match disappears while searching. `isMudSelectGroup(item)` tells a group from an
option.

<Canvas of={SelectInputStories.Searchable} />

## Searching on the server

Set `[filterWith]="null"` so the select shows `options` exactly as given, fetch results when `query`
changes, and set `loading` while the request runs (the list shows "Loading…", `loadingText`).
Debouncing, a minimum length and cancelling old requests are up to you; closing the list writes `''`
to `query`.

Results from the server are new objects, so pass `compareWith` to compare by `id`. The select
remembers the label of the selected option, but only once it has seen it, so include the selected
option in `options` at least once.

## Accessibility

The field is a combobox (`aria-expanded`, `aria-activedescendant`) named by its `<mud-label>`, which
names the list too. Messages sit in a `role="alert"` region. A polite live region announces loading
and "no results".

**Keyboard, plain select** (focus stays on the field):

- <kbd>↓</kbd> <kbd>↑</kbd> open the list, then move the highlight; <kbd>Home</kbd> <kbd>End</kbd>
  jump to the first or last option.
- <kbd>Enter</kbd> or <kbd>Space</kbd> open the list, then select the highlighted option.
- Typing letters jumps to the first option starting with them (case and diacritics ignored).
- <kbd>Esc</kbd> closes the list; <kbd>Tab</kbd> closes it and moves on.

**Keyboard, searchable select** (the field is a text input):

- Typing opens and filters the list; <kbd>↓</kbd> <kbd>↑</kbd> move the highlight.
- <kbd>Enter</kbd> selects the highlighted option; on a closed field it can submit the form.
- <kbd>Esc</kbd> closes the list and clears the text; <kbd>Tab</kbd> and clicking outside close it
  without picking anything.

## API

Selector: `mud-select-input`

<ArgTypes of={SelectInputStories} />

Method: `focus(options?)`. Content slots: `mud-label`, `[icon-start]` and `mud-inline-message`.

### Functions and types

- `MudSelectOption<T>`: `{ value: T; label: string; disabled?: boolean }`
- `MudSelectOptionGroup<T>`: `{ label: string; options: readonly MudSelectOption<T>[] }`
- `MudSelectItem<T>`: `MudSelectOption<T> | MudSelectOptionGroup<T>`
- `MudSelectCompare<T>`: `(a: T, b: T) => boolean`
- `MudSelectFilter<T>`: `(option: MudSelectOption<T>, query: string) => boolean`
- `isMudSelectGroup(item)`: whether an item is a group.
- `mudSelectDefaultFilter`: the default `filterWith`.
- `MudSelectInputVariant`: `'default' | 'destructive'`
- `MudSelectInputSize`: `'md' | 'lg'`
