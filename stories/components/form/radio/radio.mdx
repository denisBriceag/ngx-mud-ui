# Radio

A single choice from a few options. `mud-radio-group` holds the value and the form binding; each
`mud-radio` is one option. A radio can't be used outside a group; for a single on/off choice, use a
[Checkbox](?path=/docs/components-form-checkbox--docs) or a
[Switch](?path=/docs/components-form-switch--docs).

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudRadio, MudRadioGroup } from 'ngx-mud-ui/radio';
```

## Basic

`value` on the group is two-way bindable. Where you put a `<mud-label>` or `<mud-inline-message>`
decides what it belongs to:

- **Directly in the group**, the label names the group (its legend) and messages describe the group.
- **Inside a `mud-radio`**, they belong to that option only.

`disabled` on an option adds to the group's own `disabled`.

<Canvas of={RadioStories.Basic} />

## States

Set these on the group; they apply to every option. `invalid` shows the error style and sets
`aria-invalid`, `readonly` keeps the options focusable but stops changes, `required` adds a red
asterisk, and `size` is `medium` (default) or `small`.

<Canvas of={RadioStories.States} />

## Horizontal

`orientation="horizontal"` puts the options in a row, for two or three short options such as a
yes/no question. They wrap when there isn't room.

<Canvas of={RadioStories.Horizontal} />

## Reactive forms

Bind `formControl` or `formControlName` on the group, and bind `invalid` yourself, usually
`ctrl.touched && ctrl.invalid`.

<Canvas of={RadioStories.ReactiveForms} />

## Signal forms

Bind `[formField]` on the group; `invalid` and `disabled` follow the field. Values don't have to be
strings: here they're numbers. They're compared with `Object.is`, so object values must be the same
instance each time.

<Canvas of={RadioStories.SignalForms} />

## Accessibility

- The group is a `radiogroup` named by its `<mud-label>`. Group messages sit in a `role="alert"`
  region, so showing an error announces it.
- <kbd>Tab</kbd> enters the group at the selected option; arrow keys move and select.
- Call `focus()` on the group to focus the selected option, or the first enabled one.
