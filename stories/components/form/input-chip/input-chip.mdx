# Input chip

A field where the user types several values, each shown as a removable chip, such as email
recipients or keywords. It works on its own with `[(value)]`, with reactive and template-driven
forms, and with signal forms.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudInputChip } from 'ngx-mud-ui/input-chip';
import { MudLabel } from 'ngx-mud-ui/label';
```

## Basic

`value` is the list of chips (`string[]`), two-way bindable. The text being typed is a separate
`draft` model, so it never becomes part of the value until it's confirmed. <kbd>Enter</kbd> confirms
a chip, as do the `separators` characters (default `,`). A pasted list is split on separators and
new lines. <kbd>Backspace</kbd> in an empty input removes the last chip. `placeholder` shows only
while there are no chips.

## Validation and limits

`validatePattern` rejects values that don't match (it isn't named `pattern`, which signal forms
would bind). Duplicates and values past `maxChips` are rejected too. Each rejection emits `errored`
with `{ code, value }`, where `code` is `'pattern'`, `'duplicate'` or `'max'`; the field only clears
the draft, so show the reason yourself. `chipAdded` and `chipRemoved` fire for each change.

## States

`invalid`, `required`, `readonly` and `disabled` work as in a
[Text input](?path=/docs/components-form-text-input--docs). `size` is `md` (default) or
`lg`.

## Forms

Bind `formControl` (the value is `string[]`) and bind `invalid` yourself, or bind `[formField]` and
let the field drive `invalid`.

## Accessibility

- In an empty input, <kbd>←</kbd> moves focus onto the chips; <kbd>←</kbd> <kbd>→</kbd> move between
  them, and <kbd>Delete</kbd>, <kbd>Backspace</kbd>, <kbd>Enter</kbd> or <kbd>Space</kbd> removes the focused chip.
- Added, removed and rejected values are announced through a live region. The texts are
  translatable, or set your own with the `announceAdded`, `announceRemoved` and `announceRejected`
  functions.
- Each chip's remove button is named "Remove" plus the chip, or by your `removeLabel` function.
- Messages sit in a `role="alert"` region linked with `aria-describedby`. Call `focus()` to focus
  the input.

## API

Selector: `mud-input-chip`

Method: `focus(options?)`. Content slots: `mud-label` and `mud-inline-message`.

### Types

- `MudInputChipVariant`: `'default' | 'destructive'`
- `MudInputChipSize`: `'md' | 'lg'`
- `MudInputChipErrorCode`: `'pattern' | 'duplicate' | 'max'`
- `MudInputChipAdd`: `{ chip: string; chips: readonly string[] }`
- `MudInputChipRemove`: `{ chip: string; index: number; chips: readonly string[] }`
- `MudInputChipError`: `{ code: MudInputChipErrorCode; value: string }`
