# Numeric input

A field for numbers, with optional +/− steppers, limits, rounding and locale formatting. It works on
its own with `[(value)]`, with reactive and template-driven forms, and with signal forms.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
import { MudLabel } from 'ngx-mud-ui/label';
import { MudNumericInput } from 'ngx-mud-ui/numeric-input';
```

## Basic

`value` is a `number`, or **`null` when the field is empty**; don't confuse `null` with `0`.
`showSteppers` adds +/− buttons that move by `step` (default 1), as do <kbd>↑</kbd> and

<kbd>↓</kbd>. `min` and `max` stop the steppers and clamp the value when it's committed, so the user
can type past them and see it corrected on blur. `allowDecimal` and `allowNegative` set to `false`
block the separator and the minus sign as you type.

## Locale, currency and rounding

`locale` sets how the number is shown and read: with `ro-MD`, `1250.5` shows as `1.250,5`, and
grouped input is understood. Without `locale`, the number follows the
[formatting locale](?path=/docs/foundations-localization--docs) for its decimal separator and
digits, without grouping. `precision` rounds the value to that many decimals when it's committed.

Put text before or after the number with `prefix` or `suffix` (such as a currency), and an icon with
`icon-start`. `clearable` adds a × button. `errored` fires when typed input is rejected
(`'not-a-number'`) or clamped (`'out-of-range'`); `stepped` fires on each step.

## States

`variant`, `invalid`, `required`, `readonly`, `disabled` and `loading` work as in a
[Text input](?path=/docs/components-form-text-input--docs). `size` is `md` (40px, default) or
`lg` (48px). With `maxLength`, a character counter shows; describe it with `counterLabel`.

## Forms

Bind `formControl` and bind `invalid` yourself, or bind `[formField]`: with signal forms `min`,
`max`, `required` and `invalid` follow the field.

## Accessibility

- The steppers and the clear button are named "Increase", "Decrease" and "Clear" (translatable), or
  by `incrementLabel`, `decrementLabel` and `clearLabel`.
- `ariaValuetext` gives a friendlier value to announce, such as "1 250 lei".
- Messages sit in a `role="alert"` region linked with `aria-describedby`. Call `focus()` to focus
  the field.

## API

Selector: `mud-numeric-input`

<ArgTypes of={NumericInputStories} />

Method: `focus(options?)`. Content slots: `mud-label`, `[icon-start]`, `[prefix]`, `[suffix]` and
`mud-inline-message`.

### Types

- `MudNumericInputVariant`: `'default' | 'warning' | 'destructive' | 'success'`
- `MudNumericInputSize`: `'md' | 'lg'`
- `MudNumericInputErrorKind`: `'not-a-number' | 'out-of-range'`
- `MudNumericInputStep`: `{ value: number; direction: 1 | -1 }`
