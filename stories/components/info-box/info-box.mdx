# Info box

A callout inside your content: an explanation, a prerequisite or a caution about a section. For a
message about one form field use [Inline message](?path=/docs/components-inline-message--docs); for
a system message across the top of the page use [Banner](?path=/docs/components-banner--docs).

```ts
import { MudInfoBox } from 'ngx-mud-ui/info-box';
```

## Variants and emphasis

`variant` sets the meaning and icon: `neutral` (default), `moderate`, `warning` or `error`.
`emphasis="strong"` tints the surface (blue, amber or red) instead of the default grey `subtle`
one. Keep `strong` for the message nobody should miss, such as a rejection or a deadline.

The heading is your own element with the `heading` attribute. Prefer a `<p>`, so the callout
doesn't add to the page outline; an `<h3>` looks the same if it really is a heading. Without a
heading, the gap above the message disappears.

## Actions

Put the `actions` attribute on each button or link, not on a wrapper; the box lays them out in a
row 12px apart. Buttons render at size `sm` and links at size `md`.

<Canvas of={InfoBoxStories.Actions} />

## Closing

`closable` adds a close button that emits `closed`. The box doesn't remove itself: hide it in your
template, and move focus somewhere sensible, since the close button disappears with the box.

## Icon

Project a `<mud-icon>` or `<svg>` to replace the default icon, or set `hideIcon` to remove it.

<Canvas of={InfoBoxStories.Icon} />

## Accessibility

- An info box is never announced as a live region; it's part of the page. To announce a change,
  use a [Banner](?path=/docs/components-banner--docs) with `live`.
- An `aria-label` turns the box into a named `region` landmark.
- The icon is decorative; the text carries the meaning.
- The close button is named "Close" (translatable), or by `closeLabel`. It is 32×32, or 40×40 on
  touch screens.

## API

Selector: `mud-info-box`

<ArgTypes of={InfoBoxStories} />

Content slots: an optional icon, `[heading]`, the message (default content) and `[actions]`.

### Types

- `MudInfoBoxVariant`: `'neutral' | 'moderate' | 'warning' | 'error'`
- `MudInfoBoxEmphasis`: `'subtle' | 'strong'`
