# Tabs

Splits content into panels, one visible at a time. `mud-tab-group` holds the selection and keyboard
handling; each `mud-tab` has a label and its content.

```ts
import { MudTab, MudTabGroup, MudTabLabel } from 'ngx-mud-ui/tabs';
```

## Basic

Give each tab a `label`, and name the group with `aria-label` or `aria-labelledby`. `selectedIndex`
is two-way bindable, for example to sync tabs with the URL. `selectedTabChange` emits `{ index, tab }`.

Every panel is rendered when the group is created; inactive ones are hidden. Use `@if` or `@defer`
inside a tab to load heavy content only when it's needed.

## Stretched and small

`stretchTabs` spreads the tabs across the full width. `size` is `md` (default) or `sm`.

<Canvas of={TabsStories.Sizes} />

## Icons, counts and disabled tabs

For a label with an icon or other markup, put an `<ng-template mudTabLabel>` in the tab instead of
`label`. `badgeCount` shows a count after the label; it shows `0` too, so use `null` to hide it.

A `disabled` tab can't be selected, and the keyboard skips it. If the first tab is disabled, the
first enabled tab is selected.

## Controlling from code

Change `selectedIndex` to switch tabs, as in this step flow. `focusTab(index)` moves keyboard focus
to a tab, and `selectTab(index)` selects one.

## Accessibility

- The tabs follow the ARIA tabs pattern (`tablist`, `tab`, `tabpanel`).
- <kbd>←</kbd> <kbd>→</kbd> (or <kbd>↑</kbd> <kbd>↓</kbd>), <kbd>Home</kbd> and <kbd>End</kbd> move
  to another tab and select it.
- If a panel has nothing focusable in it, set `contentTabIndex` to `0` so keyboard users can reach
  its content.
