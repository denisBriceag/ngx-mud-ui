# Toast

A short message in a corner of the screen that confirms what the user just did, such as "Saved". It
disappears on its own, so never use it for something the user must read. There is no `<mud-toast>`
element: inject the `MudToast` service and call `open()`.

```ts
import { MUD_TOAST_DATA, MUD_TOAST_DEFAULT_OPTIONS, MudToast, MudToastRef } from 'ngx-mud-ui/toast';
```

## Variants

`variant` is `info` (default), `success`, `warning` or `error`, each with its own icon. `data.message`
is the text and `data.title` a heading; set either or both. With a single row (a title or a message
alone) the icon and × are centred on it; with more (title and message, or actions) they sit at the
top.

## Position and stacking

`verticalPosition` is `top` (default) or `bottom`. `horizontalPosition` is `end` (default), `start`,
`center`, `left` or `right`; `start` and `end` follow the text direction.

The newest toast sits nearest the edge. At most three toasts show at once across all positions; the
rest wait in a queue. `dismissAll()` closes every toast,
including queued ones.

<Canvas of={ToastStories.Position} />

Toasts always stay above dialogs and drawers. A common flow: confirm in a dialog, then report the
result with a toast once it closes.

<Canvas of={ToastStories.Dialog} />

## Duration and closing from code

A toast closes after `duration` ms (default 4000). `duration: 0` keeps it until you call `dismiss()`
on the `MudToastRef` that `open()` returns. The timer pauses while the pointer is over the toast
(`pauseOnHover`, default `true`) and always while focus is inside it. `showCloseButton: false`
hides the close button.

<Canvas of={ToastStories.Persistent} />

## Actions

`data.actions` takes a template for buttons under the message. `data.title` and `data.message` can be
templates too. Each template receives the `MudToastRef` as `let-ref`, so a button can call
`ref.dismiss('action')`. `dismissed` emits why the toast closed: `'timeout'`, `'close-button'`,
`'action'` or `'dismiss-all'`.

Give a toast with an action a longer `duration`. Focus never moves into a toast, so the same action
must also be available elsewhere on the page.

<Canvas of={ToastStories.Actions} />

## Custom icon and content

`data.icon` takes a template that replaces the variant's icon; draw it at 24×24 with
`currentColor`. For a whole custom body, use `openFromComponent(Component, config)` and read `data`
with `inject(MUD_TOAST_DATA)`. The ref's `instance` is set once `opened` emits.

<Canvas of={ToastStories.Component} />

## App-wide defaults

Provide `MUD_TOAST_DEFAULT_OPTIONS` to change the defaults for every toast. `maxVisible` can only be
set here. A value passed to `open()` wins over these defaults.

```ts
providers: [
  {
    provide: MUD_TOAST_DEFAULT_OPTIONS,
    useValue: { maxVisible: 5, duration: 6000, verticalPosition: 'bottom' },
  },
];
```

## Accessibility

- `info` and `success` toasts are announced politely (`role="status"`); `warning` and `error`
  assertively (`role="alert"`).
- `announcementMessage` announces a different text through the CDK `LiveAnnouncer` instead, when the
  visible text isn't what a screen reader user needs to hear.
- The close button is named "Close" (translatable), or by `closeLabel`. Toasts read the app-level
  labels, not those of the component that opened them.
- The icon is decorative.

## API

### MudToast

- `open(config: MudToastConfig): MudToastRef` opens a toast with the built-in layout.
- `openFromComponent<T, D>(component, config?: MudToastComponentConfig<D>): MudToastRef<T>` opens a
  toast with your component as its body.
- `dismissAll()` closes all toasts, including queued ones.

### Config

Shared by `open()`, `openFromComponent()` and `MUD_TOAST_DEFAULT_OPTIONS`:

- `variant` (`MudToastVariant`, default `'info'`)
- `duration` (`number`, default `4000`): ms before it closes; `0` never closes on its own.
- `pauseOnHover` (`boolean`, default `true`)
- `horizontalPosition` (`MudToastHorizontalPosition`, default `'end'`)
- `verticalPosition` (`MudToastVerticalPosition`, default `'top'`)
- `showCloseButton` (`boolean`, default `true`)
- `closeLabel` (`string`): accessible name of the close button.
- `announcementMessage` (`string`): text to announce instead of the toast's content.

`open()` also takes `data: MudToastData`:

- `message` (`string | TemplateRef`): the text. Optional when `title` is set.
- `title` (`string | TemplateRef`): a heading.
- `actions` (`TemplateRef`)
- `icon` (`TemplateRef`)

`openFromComponent()` takes `data` (any value, read with `MUD_TOAST_DATA`). `MUD_TOAST_DEFAULT_OPTIONS`
also takes `maxVisible` (`number`, default `3`).

### MudToastRef&lt;T&gt;

- `opened` (`Observable<void>`): emits once the toast is on screen, then completes.
- `dismissed` (`Observable<MudToastDismissReason>`): emits the reason once, then completes.
- `instance` (`T | undefined`): the component from `openFromComponent`, once `opened` has emitted.
- `dismiss(reason?: MudToastDismissReason)`: closes the toast (default reason `'action'`).

### Types

- `MudToastVariant`: `'info' | 'warning' | 'success' | 'error'`
- `MudToastHorizontalPosition`: `'start' | 'center' | 'end' | 'left' | 'right'`
- `MudToastVerticalPosition`: `'top' | 'bottom'`
- `MudToastDismissReason`: `'timeout' | 'close-button' | 'action' | 'dismiss-all'`
