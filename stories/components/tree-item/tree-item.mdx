# Tree item

A single navigation row: an optional icon, a label, and optional content at the end such as a note,
a badge or a tag. It's the row a [Tree](?path=/docs/components-tree--docs) is made of; on its own it
suits a flat list of links, such as a settings menu.

```ts
import { MudTreeItem } from 'ngx-mud-ui/tree-item';
```

## Basic

Add `mud-tree-item` to your own `<a>` (for a page) or `<button>` (for an action); `routerLink` and
`(click)` work as usual. `selected` marks the current page: blue background, bold label and a bar on
the leading edge. In an app, bind it to `routerLinkActive`.

Put a 20px icon before the label with `icon`. Add a second one with `selectedIcon`, usually the
filled variant, to swap it while selected. To disable a row, use a `<button>` with `disabled`; for a
link that isn't available, leave it out.

## Secondary label, badges and tags

`secondaryLabel` adds a short, lighter note at the end of the row; when space runs out, the main
label is cut first. Put a `<mud-badge size="xl">` or a `<mud-tag>` at the very end with `trailing`.

## Levels

`level` indents a row: each level past 1 adds 32px. Inside a `mud-tree`, the tree sets it for you.

<Canvas of={TreeItemStories.Levels} />

## Accessibility

- The row is your own link or button, so it keeps its native keyboard behavior and role.
- `selected` sets `aria-current="page"` on a link and `aria-current="true"` on a button.
- Icons are decorative. A badge is read as part of the row's name ("Messages 3"); if the number
  needs context, add visually hidden text to the label.

## API

Selector: `a[mud-tree-item], button[mud-tree-item]` · Exported as: `mudTreeItem`
