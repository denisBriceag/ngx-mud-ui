# Menu

A floating list of options opened from a button. `mud-menu` is for actions or a single choice on
one element. `mud-mega-menu` is a full-width navigation panel for a site header.

```ts
import { MudMenu, MudMenuItem, MudMenuTrigger } from 'ngx-mud-ui/menu';
import {
  MudMegaMenu,
  MudMegaMenuColumn,
  MudMegaMenuLink,
  MudMegaMenuOrigin,
  MudMegaMenuTrigger,
} from 'ngx-mud-ui/menu';
```

## Basic

Put `[mudMenuTriggerFor]` on a button and point it at a `<mud-menu>`. The menu emits `selected`
with the activated item's `value`. It closes on a choice, an outside click, <kbd>Esc</kbd> or the
button. A `disabled` item stays focusable but can't be activated.

<Canvas of={MenuStories.Basic} />

## Single choice

`type="selection"` makes the menu a listbox: the chosen item shows a check mark, and `value` is
two-way bindable.

<Canvas of={MenuStories.Selection} />

## Icons, checkboxes and radios

`leading="icon"` shows the item's `[icon]` content before the label. `leading="checkbox"` and
`leading="radio"` show a check box or radio; you keep their state and pass it to `selected`, as
here. Set `[closeOnSelect]="false"` to let users change several options in a row.

<Canvas of={MenuStories.Leading} />

## Sections and long labels

An item with `heading` is a divider, with an optional section label. Labels wrap to two lines and
then end in "…".

`open` renders the panel in place, in the page flow, without a trigger. Use it for a panel that's
always visible; it's ignored while a trigger shows the menu.

<Canvas of={MenuStories.Sections} />

## Nested menus

Put `[mudMenuTriggerFor]` on a `<mud-menu-item>` to open a submenu. It opens on hover or

<kbd>→</kbd>, and <kbd>←</kbd> closes it.

<Canvas of={MenuStories.Nested} />

## Position

`yPosition` is `below` (default) or `above`; `xPosition` is `after` (default, aligned to the
button's start edge) or `before`. The menu flips if there isn't room.

<Canvas of={MenuStories.Position} />

## Mega menu

A header item that opens a panel of link columns across the whole header. Mark the header with
`mudMegaMenuOrigin`, put `[mudMegaMenuTriggerFor]` on a `<button>` in it (the button renders its
own chevron), and fill `<mud-mega-menu>` with `<mud-mega-menu-column>`s of `mudMegaMenuLink`
anchors (`href` or `routerLink`).

The panel is as wide as the origin and sits right under it; buttons sharing an origin close each
other. Without an origin, the panel spans the window under the button. It closes on a link click,

<kbd>Esc</kbd>, an outside click or the button.

The button emits `opened` and `closed`; get it with `viewChild(MudMegaMenuTrigger)` to call
`open()`, `close(restoreFocus)` or `toggle()`. `panelClass` adds classes to the panel; style them
in a global stylesheet, since the panel renders in an overlay.

## Accessibility

**Menu.** A `contextual` menu is an ARIA `menu`; a `selection` menu is a `listbox`. Name the panel
with `aria-label`. The button gets `aria-haspopup` and `aria-expanded`.

- <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>↓</kbd> on the button opens the menu at the first item;
  <kbd>↑</kbd> opens it at the last.
- <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Home</kbd> <kbd>End</kbd> move between items; <kbd>Enter</kbd> or
  <kbd>Space</kbd> activates one.
- <kbd>Esc</kbd> closes the menu and returns focus to the button; <kbd>Tab</kbd> closes every open
  menu.

**Mega menu.** The panel is a `nav` named by its button's text (or the button's `aria-label`); an
`aria-label` on `<mud-mega-menu>` overrides it. Column headings are `h3`, so keep them consistent
with your page outline, and name the header's own `<nav>`.

- <kbd>Enter</kbd> or <kbd>Space</kbd> toggles the panel; <kbd>↓</kbd> opens it at the first link.
- <kbd>Tab</kbd> from the open button enters the panel; <kbd>Tab</kbd> past the last link closes it.
  <kbd>Shift</kbd>+<kbd>Tab</kbd> from the first link returns to the button.
- <kbd>Esc</kbd> closes it and returns focus to the button.

## API

### MudMenu

Selector: `mud-menu`

<ArgTypes of={MenuStories} />

### MudMenuItem

Selector: `mud-menu-item`. Content slots: `[icon]` and the label.

<ArgTypes of={MudMenuItem} />

### MudMenuTrigger

Selector: `[mudMenuTriggerFor]`

- `mudMenuTriggerFor` (input, `MudMenu`, required): the menu to open.
- `opened` / `closed` (outputs): fire when the menu opens or closes.
- `open()`, `close(restoreFocus: boolean)`, `closeAll(restoreFocus: boolean)`, `toggle()`: control it
  from code. `closeAll` also closes parent menus.

### MudMegaMenu

Selector: `mud-mega-menu`

<ArgTypes of={MudMegaMenu} />

### MudMegaMenuTrigger

Selector: `button[mudMegaMenuTriggerFor]`

<ArgTypes of={MudMegaMenuTrigger} />

Methods: `open()`, `close(restoreFocus: boolean)`, `toggle()`.

### MudMegaMenuColumn

Selector: `mud-mega-menu-column`

<ArgTypes of={MudMegaMenuColumn} />

### Other directives

- `[mudMegaMenuOrigin]`: the element the panel spans and aligns under.
- `a[mudMegaMenuLink]`: a link in a column; clicking it closes the panel.

### Types

- `MudMenuType`: `'contextual' | 'selection'`
- `MudMenuItemLeading`: `'none' | 'icon' | 'checkbox' | 'radio'`
- `MudMenuPositionX`: `'before' | 'after'`
- `MudMenuPositionY`: `'above' | 'below'`
