# Avatar

A round picture of a person: a photo, initials or an icon.

```ts
import { MudAvatar } from 'ngx-mud-ui/avatar';
```

## Content

The avatar styles what you put inside it: an `<img>` is cropped to the circle, a `<mud-icon>` or
`<svg>` is tinted, and text is shown as uppercase initials. With only `name`, it shows the initials
itself.

<Canvas of={AvatarStories.Basic} />

## Initials from a name

`name` derives the initials from the first and last word, and is also the accessible name.
`initials` sets them yourself (trimmed to two characters and uppercased). Pass `name` together with
a photo: if the photo fails to load, the initials take its place.

<Canvas of={AvatarStories.Name} />

## Sizes

`size` is `extra-small` (24px), `small` (32px), `medium` (40px, default), `large` (48px) or
`extra-large` (72px). Give an icon the matching `scale`.

<Canvas of={AvatarStories.Sizes} />

## Stack

Wrap avatars in an element with the `avatar-stack` class to overlap them. The overlap follows the
avatars' size.

<Canvas of={AvatarStories.Stack} />

## Accessibility

The avatar is an image (`role="img"`). Its accessible name is the first that is set: `label`,
`name`, "Avatar for" plus the initials, or "User avatar". Projected content is hidden from screen
readers, so the `alt` of a photo isn't read on its own. These texts are translatable, see
[Localization](?path=/docs/foundations-localization--docs).
