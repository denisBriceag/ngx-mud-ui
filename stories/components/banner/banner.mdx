# Banner

A full-width system message at the top of the page: maintenance, outages, announcements. It doesn't
block the page and stays until it's dismissed or the condition ends. For a message about one form
field use [Inline message](?path=/docs/components-inline-message--docs); for a short confirmation
such as "Saved" use [Toast](?path=/docs/components-toast--docs).

```ts
import { MudBanner } from 'ngx-mud-ui/banner';
```

## Variants and types

`variant` is `info` (default), `warning` or `error`. There is no `success`: a banner reports a
system condition, not the result of an action. `type` is `subtle` (default, tinted) or `strong`
(filled).

<Canvas of={BannerStories.Variants} />

## Custom icon

Each variant has its own icon. To replace it, project a `<mud-icon>` or `<svg>` as the first child.

<Canvas of={BannerStories.Icon} />

## Links and actions

The message is your content, so a link inside it can be an `href` or a `routerLink`. Links with
the `actions` attribute sit after the message; on phones they wrap under it. On `strong` banners,
links take the banner's text color.

<Canvas of={BannerStories.Links} />

## Dismissing

`closable` adds a close button that emits `closed`. The banner doesn't remove itself: hide it in
your template, as here.

<Canvas of={BannerStories.Closable} />

## Announcing changes

A banner isn't announced by default, so one that's on the page at load doesn't interrupt the
screen reader. `live` announces the text **when it changes while the banner is on screen**, such
as this session countdown: politely for `info` (`role="status"`), assertively for `warning` and
`error` (`role="alert"`).

`live` doesn't announce a banner that _appears_: a live region must exist before its content
changes. To announce a new message, keep your own live region in the layout and write into it.

<Canvas of={BannerStories.Live} />

## Accessibility

- Without `live`, an `aria-label` turns the banner into a named `region` landmark. With `live`, it
  names the live region.
- The close button is named "Close" (translatable, see
  [Localization](?path=/docs/foundations-localization--docs)), or `closeLabel` for one banner.
- The close button looks 24×24 but its hit area is 32×32, and 40×40 on touch screens.
