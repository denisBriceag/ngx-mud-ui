# Pagination

Pagination splits a long list into pages and lets people move between them — *1 … 4 5 6 … 20*.
It shows at most seven slots, folds the pages it cannot show into `…` buttons that open a jump
list, and hides itself when there is only one page.

```html
<mud-pagination [length]="200" [pageSize]="10" [(pageIndex)]="pageIndex" (page)="load($event)" />
```

The API follows Angular Material's paginator: `length`, `pageSize`, a **zero-based**
`pageIndex`, `disabled`, and a `page` event carrying `{ pageIndex, previousPageIndex, pageSize,
length }`. The buttons people see are numbered from 1.

## Import

```ts
import { MudPagination } from 'ngx-mud-ui/pagination';
```

## How pages fold

Up to seven pages, every page is shown. Past that, the first and last page always stay, the
current page keeps one neighbour on each side, and the rest collapse into `…`. A `…` never hides
a single page — that page's number is shown instead.

## Narrow containers

When seven slots no longer fit the space the paginator has, it drops to five (`1 … 5 … 20`).
It measures its own container, so it works in a narrow card on a wide screen too. The host is a
block-level flex container: align it with `justify-content`.

Below about 520px even five slots don't fit at the default size. For narrow containers and
phones, use `size="small"` — icon-only Prev/Next and 32px items — which needs about 270px for
its five slots.

## With a table

Assign the paginator to `MudTableDataSource.paginator`, the same way as `sort`. The data source
slices the sorted rows, keeps `length` up to date, and moves back to the last page when the data
shrinks.

```ts
constructor() {
  afterNextRender(() => {
    this.source.sort = this.sort();
    this.source.paginator = this.paginator();
  });
}
```

Re-sorting keeps the current page, like Material. To go back to page 1, call `firstPage()` from
`(sortChange)`.

### Server-side paging

Bind `length` to the server's total and load the page in `(page)`; no data source needed.

## Labels

Every string lives in the `pagination` namespace of the library's labels. Pick a language pack or
override single keys with `provideMudLabels`; pass a signal to switch language at runtime. Page
numbers follow the formatting locale. See the
[Localization guide](?path=/docs/foundations-localization--docs).

```ts
providers: [provideMudLabels({ pagination: { previous: 'Anterior', next: 'Următor', pageAria: (p, t) => `Pagina ${p} din ${t}` } })]
```

## Accessibility

- A `<nav>` landmark, named by `aria-label` (default from the labels).
- The current page carries `aria-current="page"`.
- Prev, Next and every page have a full accessible name ("Page 5 of 20").
- Each `…` is a menu button; the jump list is the library menu, with arrow-key navigation.
- When the button you used disappears (Prev on page 1, a `…` that no longer exists), focus
  moves to the current page.
