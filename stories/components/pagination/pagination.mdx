# Pagination

Splits a long list into pages: _‹ 1 … 4 5 6 … 20 ›_. It shows at most seven slots, folds the rest
into `…` buttons that open a list of the hidden pages, and hides itself when there's only one page.
The API follows Angular Material's paginator.

```ts
import { MudPagination } from 'ngx-mud-ui/pagination';
```

## Basic

Set `length` (total items) and `pageSize` (default 10). `pageIndex` is **zero-based** and two-way
bindable; the buttons show it from 1. `page` emits `{ pageIndex, previousPageIndex, pageSize,
length }` whenever the page changes.

The first and last pages always show, and the current page keeps one neighbor on each side. A `…`
never hides just one page; that page's number shows instead.

## Sizes and narrow spaces

`size` is `md` (40px, default) or `sm` (32px, Prev and Next as icons only). When seven slots
don't fit its container, the paginator drops to five (`1 … 5 … 20`). It measures its own container,
so it adapts in a narrow card on a wide screen too. Use `sm` below about 520px; it needs about
270px.

The paginator is a block-level flex container, so align it with `justify-content`. `disabled`
disables every button.

## With a table

Assign the paginator to the table's `MudTableDataSource.paginator`, as with `sort`, after the first
render. The data source shows one page of the sorted rows, keeps `length` up to date and moves back
when the data shrinks. Re-sorting keeps the current page; call `firstPage()` from `(sortChange)` to
go back to page 1, as here.

## Server-side paging

Bind `length` to the total from your server and load the page in `(page)`. No data source needed.

## Labels

Texts come from the `pagination` labels and page numbers follow the formatting locale. Use a
language pack or change single keys, see [Localization](?path=/docs/foundations-localization--docs).

## Accessibility

- The paginator is a `<nav>` named "Pagination" (translatable), or by `aria-label`.
- The current page has `aria-current="page"`. Each button has a full name, such as "Page 5 of 20".
- Each `…` opens a [Menu](?path=/docs/components-menu--docs) with arrow-key navigation.
- When the button you used disappears (Prev on page 1, a `…` that's gone), focus moves to the
  current page.

## API

Selector: `mud-pagination`

Methods: `nextPage()`, `previousPage()`, `firstPage()`, `lastPage()`, `hasNextPage()`,
`hasPreviousPage()`, `getNumberOfPages()`.

### Types

- `MudPaginationSize`: `'sm' | 'md'`
- `MudPageEvent`: `{ pageIndex: number; previousPageIndex: number; pageSize: number; length: number }`
