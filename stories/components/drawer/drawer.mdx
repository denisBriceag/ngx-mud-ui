# Drawer

A panel that slides in from an edge of the screen, such as filters or a cookie banner, over the
same backdrop as the [Dialog](?path=/docs/components-dialog--docs). There is no `<mud-drawer>`
element: inject the `MudDrawer` service and open a component or a template. The drawer is only a
surface; you supply everything inside it, including the close button.

```ts
import {
  MUD_DRAWER_DATA,
  MudDrawer,
  MudDrawerClose,
  MudDrawerRef,
  MudDrawerTitle,
} from 'ngx-mud-ui/drawer';
```

## Opening a drawer

`open()` returns a `MudDrawerRef`. Pass `data` and read it with `inject(MUD_DRAWER_DATA)` (or
`let-data` in a template). Close with a result from a button with `[mudDrawerClose]="value"`, or
from code with `MudDrawerRef.close(value)`. `closed` emits `{ result, reason }` once and completes.

Name the drawer with `mudDrawerTitle` on its heading, and give your close button an `aria-label`.

## Position and size

`position` is `'right'` (default), `'left'`, `'top'` or `'bottom'`. The drawer slides in over 225ms,
or instantly when the user prefers reduced motion.

- Left and right drawers fill the screen height. `width` sets their width (default `382px`); on
  screens up to 480px they take the full width.
- Top and bottom drawers fill the screen width. `height` sets their height (default `auto`, the
  height of the content).

Any CSS length works, and a percentage is a share of the screen.

## Scrolling content

By default the whole drawer scrolls. To keep a header and footer in view, make only the middle
block scroll with `flex: 1 1 auto; min-height: 0; overflow-y: auto` and set `display: contents` on
the drawer component's host. If that block holds only text, give it `tabindex="0"`,
`role="region"` and a name so keyboard users can scroll it.

## Requiring a choice

With `closeOnBackdrop: false` and `closeOnEscape: false`, only your own buttons close the drawer.
Turn off only `closeOnBackdrop` for a form, so a stray click outside can't discard input.

The drawer has square corners. To round the corners facing the page, set `--mud-drawer-radius` on
`.drawer` inside your `panelClass`, in a global stylesheet. To show a drawer on page load, open it
in `afterNextRender()`, so it never renders on the server.

## Accessibility

- The drawer is named by `mudDrawerTitle`, or by `ariaLabel` when there's no heading (`ariaLabel`
  wins when both are set).
- On open, focus moves to the first focusable element (change it with `autoFocus`) and stays in the
  drawer. On close it returns to where it was, unless `restoreFocus: false`.
- <kbd>Tab</kbd> and <kbd>Shift</kbd>+<kbd>Tab</kbd> cycle inside the drawer; <kbd>Esc</kbd> closes
  it unless `closeOnEscape: false`.

## API

### MudDrawer

`open<R, D>(componentOrTemplate, config?: MudDrawerConfig<D>): MudDrawerRef<R>` opens a drawer.
The service is provided in root.

### MudDrawerConfig

- `data` (`D`): passed through `MUD_DRAWER_DATA`, or as the template's implicit variable.
- `position` (`'top' | 'right' | 'bottom' | 'left'`, default `'right'`): the edge.
- `width` (`string`, default `'382px'`): width of a left or right drawer.
- `height` (`string`, default `'auto'`): height of a top or bottom drawer.
- `closeOnBackdrop` (`boolean`, default `true`): closes on a backdrop click.
- `closeOnEscape` (`boolean`, default `true`): closes on <kbd>Esc</kbd>.
- `ariaLabel` (`string`): accessible name when there's no `mudDrawerTitle`.
- `autoFocus` (`'first-tabbable' | 'first-heading' | 'dialog' | string | boolean`): where focus goes on
  open.
- `restoreFocus` (`boolean`, default `true`): returns focus on close.
- `panelClass` (`string | string[]`): extra classes on the overlay panel.

### MudDrawerRef&lt;R&gt;

- `closed` (`Observable<MudDrawerCloseResult<R>>`): emits `{ result, reason }` once, then completes.
- `backdropClick` (`Observable<MouseEvent>`): backdrop clicks, also when they don't close the drawer.
- `close(result?: R, reason?: MudDrawerCloseReason)`: closes the drawer; the reason defaults to
  `'action'`.

`MudDrawerCloseReason` is `'action'` (your buttons or `close()`), `'backdrop'` or `'escape'`. The
drawer has no exit animation.

### Directives

- `[mudDrawerTitle]`: the heading; names the drawer.
- `[mudDrawerClose]`: closes the drawer with the bound value (no value: `undefined`). Input `type`
  sets the button type (default `'button'`).

### Types

- `MudDrawerPosition`: `'top' | 'right' | 'bottom' | 'left'`
- `MudDrawerCloseReason`: `'backdrop' | 'escape' | 'action'`
- `MudDrawerCloseResult<R>`: `{ result: R | undefined; reason: MudDrawerCloseReason }`
