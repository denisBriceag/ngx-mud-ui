# Button

`mudButton` and `mudIconButton` are attribute directives for a native `<button>` or `<a>`. The
element keeps its native behavior: `type`, `form`, `href`, `routerLink` and event bindings work as
usual.

```ts
import { MudButton, MudIconButton } from 'ngx-mud-ui/button';
```

## Basic

Add `mudButton` to a `<button>`. Always set `type`: an unset type inside a `<form>` submits it.

<Canvas of={ButtonStories.Basic} />

## Variants and colors

The variant is the directive's own value: `filled` (default, also `mudButton` with no value),
`outlined` or `text`. `color` picks the color. `secondary` and `neutral` exist for `filled` only;
any other unsupported pair falls back to `primary` with a dev-mode warning.

<Canvas of={ButtonStories.Variants} />

## Sizes and shapes

`size` is `large` (default), `medium` or `small`. `shape="circular"` rounds the corners fully.

<Canvas of={ButtonStories.Sizes} />

## Icons

Icons are projected content: put a `<mud-icon>` before or after the text. For an icon-only action
use `mudIconButton`, a transparent circle in `medium` (40px, default) or `small` (32px) size. It
needs an `aria-label`, `aria-labelledby` or `title`, and warns in dev mode without one.

<Canvas of={ButtonStories.Icons} />

## Loading

While `loading` is set, the button shows a spinner, ignores clicks (your `(click)` handler doesn't
run) and exposes `aria-busy="true"`. It stays focusable, so keyboard users keep their place.

## Links

On an `<a>`, `disabled` sets `aria-disabled="true"` and `tabindex="-1"` and blocks activation, since
links can't be natively disabled.

<Canvas of={ButtonStories.Link} />

## Full width

`fullWidth` stretches the button to its container, for stacked form actions.

<Canvas of={ButtonStories.FullWidth} />

## Platform buttons

Entry points to the government platforms (mpay, mpass, msign, mpower, mdelivery). Keep
`mudButton` on the button and add the `btn-badge btn-badge--{primary|neutral} btn-badge--{platform}`
classes. `loading` and `disabled` work as usual.

<ArgTypes of={MudIconButton} />

### Types

- `MudButtonVariant`: `'filled' | 'outlined' | 'text'`
- `MudButtonColor`: `'primary' | 'secondary' | 'strict' | 'neutral' | 'destructive'`
- `MudButtonSize`: `'large' | 'medium' | 'small'`
- `MudButtonShape`: `'rectangular' | 'circular'`
- `MudIconButtonSize`: `'medium' | 'small'`
