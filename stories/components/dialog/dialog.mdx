# Dialog

A modal dialog built on the CDK dialog. It traps focus, blocks page scroll and closes with the ×
button, a backdrop click or <kbd>Esc</kbd>. There is no `<mud-dialog>` element: inject the
`MudDialog` service and open a component or a template.

```ts
import {
  MUD_DIALOG_DATA,
  MudDialog,
  MudDialogActions,
  MudDialogClose,
  MudDialogContent,
  MudDialogImage,
  MudDialogRef,
  MudDialogTitle,
} from 'ngx-mud-ui/dialog';
```

## Confirm

`open()` returns a `MudDialogRef`. Its `closed` observable emits once with `{ result, reason }` and
then completes, so you don't need to unsubscribe. Inside the dialog, `[mudDialogClose]` closes it
with the bound value as the result.

<Canvas of={DialogStories.Confirm} />

## Passing data and returning a result

Pass `data` in the config and inject it with `MUD_DIALOG_DATA`. Inject `MudDialogRef` to close the
dialog from code with `close(result)`. A dismissal (×, backdrop, <kbd>Esc</kbd>) gives
`result: undefined`.

For a form, set `closeOnBackdrop: false` so a stray click can't discard what was typed. Set
`closeOnEscape: false` too when the user must answer.

## Sizes

`size` is `sm` (480px), `md` (588px, default) or `lg` (720px). On phones every dialog is
`min(350px, 100vw - 32px)` wide. The height is capped by the library.

<Canvas of={DialogStories.Sizes} />

## Image and stacked actions

`[mudDialogImage]` on the first child makes a full-width image under the × button. Set its height
yourself: 280px on desktop and 180px on phones are recommended.

`layout="stacked"` on `[mudDialogActions]` gives full-width buttons with the primary on top. Keep
the secondary button first in the markup in both layouts. Below 480px, actions always stack.

<Canvas of={DialogStories.Image} />

## Long content

Only `[mudDialogContent]` scrolls; the title and actions stay in place. A long title is cut after
three lines. `autoFocus` decides where focus lands on open; here it's the title, so the text is read
from the top.

<Canvas of={DialogStories.LongContent} />

## From a template

`open()` also takes a `TemplateRef`. `data` arrives as the template's implicit variable
(`let-data`), and `[mudDialogClose]` works inside it.

## Accessibility

- The CDK provides the focus trap, focus restore, `role="dialog"` and `aria-modal="true"`.
- `[mudDialogTitle]` names the dialog. Without a title, set `ariaLabel` in the config.
- The × button is named "Close" (translatable), or by `closeLabel`. The dialog reads the app-level
  labels, not those of the component that opened it.
- With the default config, focus lands on the × button. For a confirm dialog, consider focusing the
  least destructive action: `autoFocus: '.cancel-button'`.

## API

### MudDialog

`open<R, D>(componentOrTemplate, config?: MudDialogConfig<D>): MudDialogRef<R>` opens a dialog.
The service is provided in root.

### MudDialogConfig

- `data` (`D`): passed to the dialog through `MUD_DIALOG_DATA`, or as the template's implicit
  variable.
- `size` (`'sm' | 'md' | 'lg'`, default `'md'`): width.
- `showCloseButton` (`boolean`, default `true`): shows the × button.
- `closeLabel` (`string`): accessible name of the × button.
- `closeOnBackdrop` (`boolean`, default `true`): closes on a backdrop click.
- `closeOnEscape` (`boolean`, default `true`): closes on <kbd>Esc</kbd>.
- `ariaLabel` (`string`): accessible name when there's no `[mudDialogTitle]`.
- `autoFocus` (`'first-tabbable' | 'first-heading' | 'dialog' | string | boolean`): where focus
  goes on open; a string is a CSS selector inside the dialog.
- `restoreFocus` (`boolean`, default `true`): returns focus to the opener on close.
- `panelClass` (`string | string[]`): extra classes on the overlay panel.

### MudDialogRef&lt;R&gt;

- `closed` (`Observable<MudDialogCloseResult<R>>`): emits `{ result, reason }` once, then completes.
- `backdropClick` (`Observable<MouseEvent>`): backdrop clicks, also when they don't close the
  dialog.
- `close(result?: R, reason?: MudDialogCloseReason)`: closes the dialog; the reason defaults to
  `'action'`.

### Close reasons

`MudDialogCloseReason` is one of:

- `'action'`: `[mudDialogClose]` or `close()`. Also when the dialog is closed by the system, such
  as on navigation.
- `'close-button'`: the × button.
- `'backdrop'`: a backdrop click.
- `'escape'`: the <kbd>Esc</kbd> key.

### Directives

- `[mudDialogTitle]`: the title; names the dialog.
- `[mudDialogContent]`: the body, and the only part that scrolls.
- `[mudDialogActions]`: the button row. Input `layout`: `'inline'` (default) or `'stacked'`.
- `[mudDialogClose]`: closes the dialog with the bound value. Input `type` sets the button type
  (default `'button'`).
- `[mudDialogImage]`: a full-width image at the top.

### Types

- `MudDialogSize`: `'sm' | 'md' | 'lg'`
- `MudDialogCloseReason`: `'backdrop' | 'escape' | 'close-button' | 'action'`
- `MudDialogCloseResult<R>`: `{ result: R | undefined; reason: MudDialogCloseReason }`
