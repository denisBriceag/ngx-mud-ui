# Inline message

A short message with an icon, on its own or under a form field as its hint or error.

```ts
import { MudInlineMessage } from 'ngx-mud-ui/inline-message';
```

<Canvas of={InlineMessageStories.Playground} />
<Controls of={InlineMessageStories.Playground} />

## Variants and sizes

`variant` is `info` (default), `success`, `warning` or `error`. `info` colors only the icon, so it
reads as neutral help text; the others color the text too. `size` is `md` (14px text, 20px
icon, default) or `sm` (12px text, 16px icon).

<Canvas of={InlineMessageStories.Variants} />

## Icon and wrapping

Project a `<mud-icon>` or `<svg>` to replace the icon, or set `hideIcon` to remove it, for example
in a stack of messages. A long message wraps, and the icon stays on the first line.

<Canvas of={InlineMessageStories.Icon} />

## With a form field

Inside a field, the message is linked to the input with `aria-describedby` and wrapped in a
`role="alert"` region, so a new error is announced. When and whether to show it is up to you; here
the error appears after the user leaves the field.

Outside a field, give the message an `id` and point the control's `aria-describedby` at it.

<Canvas of={InlineMessageStories.Field} />

## Accessibility

The message on its own is not a live region and announces nothing. The field it's placed in does
the announcing.

## API

Selector: `mud-inline-message`

<ArgTypes of={InlineMessageStories} />

### Types

- `MudInlineMessageVariant`: `'info' | 'warning' | 'success' | 'error'`
- `MudInlineMessageSize`: `'sm' | 'md'`
