# Badge

A small count or dot that flags new or pending items. It comes in two forms:

- **`<mud-badge>`** — an inline element you place in content: a button label, a
  tab label, a tree or sidebar item.
- **`[mudBadge]`** — a directive that pins the same badge to a corner of its host,
  typically a button or an icon.

Both share one vocabulary: `size` `xs`–`xl`, `variant` for the colour, `type`
`numbered` or `dot`.

## Import

```ts
import { MudBadge, MudCornerBadge } from 'ngx-mud-ui/badge';

@Component({
  imports: [MudBadge, MudCornerBadge],
  template: `
    <a mud-tree-item routerLink="/inbox">Inbox <mud-badge trailing [count]="3" variant="neutral" size="xl" /></a>
    <button mudButton mudBadge="5" badgeVariant="danger">Inbox</button>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## Usage tips

- **`<mud-badge>` is a named image by default.** It is named by its visible count, or by
  `notificationLabel` when it shows a dot. Without `notificationLabel` the dot uses the
  `badge.notification` label (English 'Notification'). This is one place where a blank value keeps a meaning:
  `notificationLabel=""` makes the dot decorative, with no role and no name. Set `aria-label` when the number alone
  is ambiguous ("3 unread"). Add `live` on the one badge whose changes should be
  announced (`role="status"`); a sidebar full of counts stays quiet otherwise.
- **Nudge a corner badge with `--mud-badge-offset-top/right/bottom/left`** on the
  host — positive values pull it inward from its anchored edge (the avatar uses
  them to sit the badge on its circumference).
- **`mudBadge` carries the corner badge's content** and accepts a string, a
  number, or `null`. `null` removes the badge rather than rendering an empty one.
- **`max` / `badgeMax` truncate large counts** — at 99, a value of 150 renders as
  `99+`.
- **Set `badgeDescription` on a corner badge whenever the number alone is
  ambiguous.** A bare `5` on an Inbox button reads as "Inbox 5"; a description
  like "5 unread messages" states what it counts.
- **`xs` is dot-only.** A numbered badge at that size renders as a dot.
- **The host needs its own accessible name.** A corner badge decorates an
  element; it does not name it.
