# Badge

A small count or dot that flags new or pending items. `<mud-badge>` sits inline in content, such as
a button or a menu item. The `mudBadge` directive pins the same badge to a corner of an element.

```ts
import { MudBadge, MudCornerBadge } from 'ngx-mud-ui/badge';
```

## Sizes and dots

`size` is `xl` (24px), `lg` (20px), `md` (16px, default), `sm` (12px) or `xs` (8px). `type="dot"`
shows a dot without text. `xs` is always a dot: a numbered `xs` badge renders as one.

<Canvas of={BadgeStories.Sizes} />

## Variants

`default`, `brand`, `positive`, `warning` and `danger` (default) are the official MUD colors. `dark`
looks like `default`. `light` is for dark surfaces. `neutral` and `accent` are extras with no
official equivalent.

<Canvas of={BadgeStories.Variants} />

## Maximum and disabled

A count above `max` (default 99) renders as `{max}+`. `disabled` is visual only; the surrounding
control announces the state.

<Canvas of={BadgeStories.Max} />

## Accessible name and live updates

A numbered badge is read as its count, and a dot as "Notification" (or your `notificationLabel`).
Set `aria-label` when the number alone is ambiguous, as here. `aria-label=""` or
`notificationLabel=""` makes the badge decorative.

Add `live` to the one badge whose changes should be announced (`role="status"`). It is off by
default, so a sidebar full of counts stays quiet.

<Canvas of={BadgeStories.Live} />

## Corner badge

`mudBadge` takes the content (a count or text; `null` removes the badge) and pins it to a corner
with `badgePosition`. The element keeps its own content and accessible name. Use
`badgeDescription` to say what the badge means: screen readers then hear "Inbox, 5 unread
messages" instead of "Inbox 5".

To nudge the badge, set `--mud-badge-offset-top`, `-right`, `-bottom` or `-left` on the element.
Positive values move it inward.

### Types

- `MudBadgeType`: `'numbered' | 'dot'`
- `MudBadgeVariant`: `'default' | 'brand' | 'positive' | 'warning' | 'danger' | 'dark' | 'light' | 'neutral' | 'accent'`
- `MudBadgeSize`: `'xs' | 'sm' | 'md' | 'lg' | 'xl'`
- `MudBadgePosition`: `'above after' | 'above before' | 'below before' | 'below after' | 'before' | 'after' | 'above' | 'below'`
