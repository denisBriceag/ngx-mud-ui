# Tooltip

`mudTooltip` shows a short text bubble next to an element on hover or focus. The `coach` variant
stays open for onboarding hints. A tooltip is an extra; don't put anything essential only in it, since
touch users may never see it.

```ts
import { MudTooltip } from 'ngx-mud-ui/tooltip';
```

## Basic

The directive's value is the text; an empty text never opens. `tooltipSize` is `sm` (default) or
`lg`, and `tooltipTitle` adds a bold line above the text. Long text wraps at `tooltipMaxWidth`
(default `280px`).

<Canvas of={TooltipStories.Basic} />

## Placement

`tooltipPlacement` sets the side and alignment (default `top-center`). When there isn't room, the
tooltip flips to the other side, then tries the other alignments.

<Canvas of={TooltipStories.Placements} />

## On an icon button

The tooltip describes its element (`aria-describedby`). When it only repeats the element's name, as
on an icon button labelled "Download", set `[tooltipDescribesTrigger]="false"` so the name isn't read
twice.

<Canvas of={TooltipStories.Icon} />

## Triggers

`tooltipTrigger` is `hover` (default; also opens on keyboard focus), `click`, `focus` or `manual`.
A `manual` tooltip only opens and closes through `show()` and `hide()`, via a template reference
(`#tip="mudTooltip"`); `isOpen` tells you whether it's showing. `tooltipShowDelay` (200ms) and
`tooltipHideDelay` (150ms) tune hover timing.

<Canvas of={TooltipStories.Triggers} />

## Links and close buttons

`tooltipInteractive` keeps the bubble open while the pointer is over it. `tooltipClosable` adds a
close button.

<Canvas of={TooltipStories.Interactive} />

## Coach

`tooltipVariant="coach"` is for onboarding: it stays open until <kbd>Esc</kbd>, its close button or
a click outside, shows the hint "Press Esc to close", and ignores hover and focus. `tooltipClosed`
emits why the user closed it (`'escape'`, `'close-button'`, `'click-outside'`, `'click-trigger'` or
`'blur'`), for example to record whether a hint was read.

<Canvas of={TooltipStories.Coach} />

## Accessibility

- The tooltip has `role="tooltip"` and describes its element through `aria-describedby`.
- <kbd>Esc</kbd> closes it.
- The close button ("Close") and the coach hint ("Press Esc to close") are translatable, or set
  `tooltipCloseLabel` and `tooltipCoachHint`. A `provideMudLabels` in a component's `providers` also
  reaches that component's tooltips.

## API

Selector: `[mudTooltip]` · Exported as: `mudTooltip`

<ArgTypes of={TooltipStories} />

Methods: `show()`, `hide()`. Property: `isOpen`.

### Types

- `MudTooltipPlacement`: `'top-left' | 'top-center' | 'top-right' | 'bottom-left' | 'bottom-center' |
'bottom-right' | 'left-top' | 'left-center' | 'left-bottom' | 'right-top' | 'right-center' |
'right-bottom'`
- `MudTooltipSize`: `'sm' | 'lg'`
- `MudTooltipTrigger`: `'hover' | 'click' | 'focus' | 'manual'`
- `MudTooltipVariant`: `'default' | 'coach'`
- `MudTooltipCloseReason`: `'blur' | 'escape' | 'close-button' | 'click-outside' | 'click-trigger'`
