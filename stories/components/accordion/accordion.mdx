# Accordion

An expandable section built on the CDK accordion. `mud-accordion` is one section; wrap several in
`mud-accordion-group` to separate and coordinate them. The header holds a `mud-accordion-title`
and an optional `mud-accordion-description`.

```ts
import {
  MudAccordion,
  MudAccordionDescription,
  MudAccordionGroup,
  MudAccordionHeader,
  MudAccordionTitle,
} from 'ngx-mud-ui/accordion';
```

## Group

A group draws the separators between sections and moves focus between headers with

<kbd>↑</kbd> <kbd>↓</kbd> <kbd>Home</kbd> <kbd>End</kbd>. Several sections can be open at once by
default; set `[multi]="false"` so opening one closes the others.

<Canvas of={AccordionStories.Group} />

## Controlling the state

`expanded` is two-way bindable. Through a template reference you can call `toggle()`, `open()` and
`close()`. `afterExpand` and `afterCollapse` fire once the animation has finished, which is the
moment to measure, scroll or move focus. (`expandedChange`, `opened` and `closed` fire as the state
flips.)

<Canvas of={AccordionStories.Controlled} />

## Disabled

A disabled section can't be opened. It stays in the tab order with `aria-disabled="true"`, so
keyboard and screen-reader users still find it.

<Canvas of={AccordionStories.Disabled} />

## Appearance, size and toggle position

Set on the group:

- `appearance="trail-sites"` tints open sections with the brand-secondary surface, for the eGov
  trail-sites pattern.
- `size="sm"` uses the compact header at every screen width, for dense surfaces.
- `iconPosition="left"` puts the toggle before the heading.

`hideToggle` on a section hides the toggle; the header still opens it on click.

<Canvas of={AccordionStories.Appearance} />

## Leading icon

Put an icon in the header with the `icon-start` attribute. Use 20px (`[scale]="20"`). It takes the
toggle's color and is part of the header button.

<Canvas of={AccordionStories.Icon} />

## Trailing content

Elements with the `trailing` attribute (tags, counts, edit links) sit between the heading and the
toggle, which suits a "check your answers" page. They are outside the header button:

- A link or button there is its own tab stop, and clicking it doesn't toggle the section. A click
  on plain content, such as a tag, does.
- It isn't part of the section's accessible name.
- In a disabled section, its links and buttons can't be focused or clicked. Bind `disabled` on your
  own buttons there.

Below 768px of screen width, or when the accordion is narrower than 600px, trailing content moves
to its own line under the heading.

<Canvas of={AccordionStories.Trailing} />

## Long content

A long heading wraps, and an unbroken word (a link, an IDNP) breaks anywhere. A long description
stays on one line and ends in "…", though screen readers still read all of it. Long trailing
content wraps.

## API

### MudAccordion

Selector: `mud-accordion`

<ArgTypes of={AccordionStories} />

Inherited from the CDK's `CdkAccordionItem`:

- `expanded` (input, `boolean`, default `false`): whether the section is open. Two-way bindable.
- `disabled` (input, `boolean`, default `false`): blocks toggling.
- `expandedChange` (output, `boolean`): fires when the open state changes, before the animation.
- `opened` / `closed` (outputs): fire when the section opens or closes, before the animation.
- `toggle()`, `open()`, `close()`: change the state from code.

### MudAccordionGroup

Selector: `mud-accordion-group`

<ArgTypes of={MudAccordionGroup} />

Inherited from the CDK's `CdkAccordion`:

- `multi` (input, `boolean`, default `true`): lets several sections stay open at once.
- `openAll()`, `closeAll()`: open or close every section (`openAll()` needs `multi`).

### MudAccordionHeader

Selector: `mud-accordion-header`

<ArgTypes of={MudAccordionHeader} />

Content slots: `mud-accordion-title`, `mud-accordion-description`, `[icon-start]` and `[trailing]`.

### Types

- `MudAccordionAppearance`: `'default' | 'trail-sites'`
- `MudAccordionSize`: `'sm' | 'md'`
- `MudAccordionIconPosition`: `'right' | 'left'`
