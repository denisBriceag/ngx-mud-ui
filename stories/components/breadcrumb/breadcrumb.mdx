# Breadcrumb

Shows where the user is in a service and lets them step back up: _Acasă › Servicii › Cerere nouă_.
You write the `<nav>`, `<ol>`, `<li>` and links; the directives add the separators, fold long
trails into a `…` menu, shorten long labels and switch to a back link in narrow spaces. Your own
`<a>` stays in place, so `routerLink` and click handlers work as usual.

```ts
import { MudBreadcrumb, MudBreadcrumbItem } from 'ngx-mud-ui/breadcrumb';
```

## Basic

Put `mudBreadcrumb` on a `<nav>` containing an `<ol>`, and `mudBreadcrumbItem` on each `<li>`. Each
crumb holds one link or button. Mark the current page with `active`; a plain `<span>` suits it,
since it goes nowhere.

<Canvas of={BreadcrumbStories.Basic} />

## Collapsing

With more crumbs than `maxVisible` (default 4, minimum 2), the trail keeps the first crumb and the
last two, and folds the rest into a `…` menu in their original order.

<Canvas of={BreadcrumbStories.Collapsed} />

## Long labels

A label longer than 30 characters is cut with "…", and a tooltip shows the full text on hover and
on keyboard focus.

<Canvas of={BreadcrumbStories.LongLabel} />

## Icons

Put a 16px icon inside the link with the `icon-start` attribute. For an icon-only crumb, name the
link with `aria-label` and give the crumb a `label`, which the `…` menu and the back link show.

<Canvas of={BreadcrumbStories.Icon} />

## States

`disabled` greys a crumb out and blocks it, but keeps it focusable so keyboard users hear its state.

<Canvas of={BreadcrumbStories.States} />

## Narrow containers

When the breadcrumb's container is narrower than 640px, the trail becomes a single back link to the
nearest crumb that isn't disabled. It's a container query, so it reacts to the space the breadcrumb
has, not the window size. Set `[responsive]="false"` to always show the full trail.

<Canvas of={BreadcrumbStories.Narrow} />

## Accessibility

- The `<nav>` is a landmark named "Breadcrumb" (translatable), or by `label`. An `aria-label` you
  write on it wins.
- The current page gets `aria-current="page"` and a disabled crumb `aria-disabled="true"`, on the
  link inside the crumb (or on the `<li>` when there's no link).
- Separators are drawn with CSS, so they are never read aloud.
- The `…` button is a disclosure (`aria-expanded`); <kbd>Esc</kbd> closes it and returns focus. Its
  name is "Show collapsed pages", or `overflowLabel`.
- A `mudBreadcrumbItem` outside an `<li>` in a list logs a warning in development.
