# Chip

A compact pill with two roles, chosen with `type`: a `filter` chip (default) is a toggle button,
and an `input` chip shows a value the user entered, optionally with a remove button. To type and
collect values in a field, see [Input chip](?path=/docs/components-form-input-chip--docs).

```ts
import { MudChip } from 'ngx-mud-ui/chip';
```

## Filter chips

A filter chip toggles `selected` on click (two-way bindable) and exposes `aria-pressed`.

- `selectionMode="mono"` (default) only changes the color. Keeping one chip active at a time is up
  to you: react to `selectedChange`, as in the first group.
- `selectionMode="multi"` adds a check mark while selected, for picking several.

Wrap a set of chips in an element with `role="group"` and an `aria-label`.

<Canvas of={ChipStories.Filter} />

## Input chips

`type="input"` makes a static token, not a button. With `removable`, a close button emits `removed`;
remove the chip from your list in response. The close button is named "Remove" plus `label`
(translatable), or by your `removeLabel` function.

## Icon, avatar and count

Project a leading icon with `icon-start` (16px) or a small image with `avatar`. `count` adds a
number after the label; it shows for any number, including `0`.

<Canvas of={ChipStories.Content} />

## Sizes and states

`size` is `md` (36px, default) or `sm` (28px). `disabled` blocks toggling and removing.

<Canvas of={ChipStories.Sizes} />

## API

Selector: `mud-chip`

<ArgTypes of={ChipStories} />

Content slots: `[avatar]`, `[icon-start]` and the label (default content).

### Types

- `MudChipType`: `'filter' | 'input'`
- `MudChipSize`: `'sm' | 'md'`
- `MudChipSelectionMode`: `'mono' | 'multi'`
