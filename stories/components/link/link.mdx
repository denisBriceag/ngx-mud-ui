# Link

`mudLink` styles a native `<a>`. The anchor keeps its behavior, so `href`, `target`, `routerLink`
and event bindings work as usual. Use a link to go somewhere; for an action, use a
[Button](?path=/docs/components-button--docs).

```ts
import { MudLink } from 'ngx-mud-ui/link';
```

## Color, underline and disabled

The color is the directive's value: `primary` (default, also `mudLink` with no value) or `strict`
(the text color). `underline` is `always` (default), `hover` or `none`. Without an underline, color
is the only cue, so only drop it where the link is obviously interactive, such as in a menu.

`disabled` sets `aria-disabled`, removes the link from the tab order and blocks activation. The
`href` stays.

## Sizes

`size` is `lg`, `md` (default), `sm` or `xs`.

<Canvas of={LinkStories.Sizes} />

## New tab

A link with `target="_blank"` gets an external-link icon after its text (unless it already ends in
an icon) and `rel="noopener noreferrer"` (unless you set `rel`). `[external]="false"` hides the
icon.

<Canvas of={LinkStories.External} />

## Hit area

The link's clickable area extends beyond its text: 32px high for a mouse (`pointer`), 40px for
touch (`touch`). `auto` (default) picks by device. In running text, set `touchTarget="none"` so the
link doesn't overlap the lines above and below.

## API

Selector: `a[mudLink]` · Exported as: `mudLink`

<ArgTypes of={LinkStories} />

### Types

- `MudLinkStyle`: `'primary' | 'strict'`
- `MudLinkSize`: `'xs' | 'sm' | 'md' | 'lg'`
- `MudLinkUnderline`: `'always' | 'hover' | 'none'`
- `MudLinkTouchTarget`: `'auto' | 'pointer' | 'touch' | 'none'`
