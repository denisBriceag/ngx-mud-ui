# Sidebar

The side navigation of a page: groups of links that can shrink to an icon-only rail. Inside
`mud-sidebar-layout` it lines up with the page's 12-column grid.

```ts
import {
  MudSidebar,
  MudSidebarContent,
  MudSidebarGroup,
  MudSidebarHeader,
  MudSidebarItem,
  MudSidebarLayout,
  MudSidebarToggle,
} from 'ngx-mud-ui/sidebar';
```

## Basic

A sidebar is built from:

- `<mud-sidebar>`: the panel, a navigation landmark. Give it an `aria-label`.
- `[mudSidebarHeader]` (optional): content at the top, such as a profile, the toggle or a main
  action.
- `<mud-sidebar-group>`: a section with an optional `heading`. It can hold rows or anything else:
  chips, a contact list, a tree.
- `mud-sidebar-item`: a row, on your own `<a>` or `<button>`.

Bind a row's `selected` to `routerLinkActive` to mark the current page. On its own the panel is
368px wide.

<Canvas of={SidebarStories.Basic} />

## Rows

A row has the same look and slots as a [Tree item](?path=/docs/components-tree-item--docs): an
`[icon]`, an optional `[selectedIcon]` (a filled variant shown while selected), the label, a
`[secondaryLabel]` note and a `[trailing]` badge or tag. For counts, use a `<mud-badge>` with
`size="xl"`: `neutral` for a count, `danger` for notifications.

Only a `<button>` row can be `disabled`; for a link that isn't available, leave it out.

Every group except the first gets a divider above it; `divider` overrides that for one group. The
header doesn't count as a group. Groups must be direct children of `mud-sidebar`.

## The compact rail

`collapsed` shrinks the sidebar to a 68px rail; it's two-way bindable. Each row then shows only its
icon in a 40×40 circle, and its label in a tooltip on hover or focus. Headings are hidden. **Every
row needs an icon**, since the icon is all the rail shows.

A `button[mudSidebarToggle]` inside the sidebar switches it and keeps `aria-expanded` up to date.
Name it after the menu ("Menu"), not the action, and keep it outside any `@if`, or it loses focus
when the rail switches. A bare `collapsed` attribute doesn't compile; write `[collapsed]="true"`.

## Page layout

`<mud-sidebar-layout>` places the sidebar and the element marked `mudSidebarContent` on a grid up to
1248px wide (twelve 68px columns, 32px gaps, 40px side padding): the full sidebar takes 4 columns,
the rail 1. The sidebar keeps its own height.

Below 768px the layout stacks: the sidebar goes full width above the content, loses its border and
toggle, and is always drawn in full. Your `collapsed` value is kept for wider screens. For a phone
menu that slides in, put the sidebar in a [Drawer](?path=/docs/components-drawer--docs).

Your own header and group content need a rail version too. Get the sidebar with
`#sb="mudSidebar"` and switch on `sb.compact()`, which is what's actually drawn. (`collapsed()` stays
`true` below 768px, where the sidebar is still drawn in full; `narrow()` tells you the screen is
below 768px.)

## Nested pages

To nest pages, put a [Tree](?path=/docs/components-tree--docs) in a group. In the rail only the
tree's top level shows; opening a section expands the sidebar first.

## Accessibility

- The sidebar is a navigation landmark: name it with `aria-label` or `aria-labelledby` (it warns in
  development without one). A group with a `heading` is a group named by it.
- A selected link row has `aria-current="page"`; a button row `aria-current="true"`.
- The toggle has `aria-expanded` and `aria-controls` pointing at the sidebar's `id`.
- In the rail, labels are hidden visually but still read. In a tree, a key that would move focus
  to a hidden row expands the sidebar first.
- Give icon-only buttons in your own rail content an `aria-label`.

## API

### MudSidebar

Selector: `mud-sidebar` · Exported as: `mudSidebar`

<ArgTypes of={SidebarStories} />

Signals: `compact()` (drawn as the rail), `narrow()` (screen below 768px). Method: `toggle()`.

### MudSidebarGroup

Selector: `mud-sidebar-group` · Exported as: `mudSidebarGroup`

<ArgTypes of={MudSidebarGroup} />

### MudSidebarItem

Selector: `a[mud-sidebar-item], button[mud-sidebar-item]` · Exported as: `mudSidebarItem`

<ArgTypes of={MudSidebarItem} />

Content slots: `[icon]`, `[selectedIcon]`, the label, `[secondaryLabel]` and `[trailing]`.

### Other parts

- `[mudSidebarHeader]`: content at the top of the sidebar.
- `button[mudSidebarToggle]` (exported as `mudSidebarToggle`): switches `collapsed`.
- `mud-sidebar-layout` (exported as `mudSidebarLayout`): the page grid.
- `[mudSidebarContent]`: the page content next to the sidebar.
