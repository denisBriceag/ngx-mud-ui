# Spinner

Shows that something is loading when you can't tell how long it will take. For a button that's
working, use the button's own `loading` state instead.

```ts
import { MudSpinner } from 'ngx-mud-ui/spinner';
```

<Canvas of={SpinnerStories.Playground} />
<Controls of={SpinnerStories.Playground} />

## Sizes

`size` is `xs` (16px), `sm` (20px), `md` (32px, default) or `lg` (40px).

<Canvas of={SpinnerStories.Sizes} />

## Variants

`variant` is `brand` (default), `dark`, `light` for dark surfaces, or `light-on-color` for
saturated ones, where the brand color loses contrast.

<Canvas of={SpinnerStories.Variants} />

## While content loads

Show the spinner in place of the content, and mark the region `aria-busy` while it loads.

<Canvas of={SpinnerStories.Loading} />

## Accessibility

The spinner is a status region (`role="status"`) with hidden text that screen readers read. The text
is "Loading" (translatable); set `aria-label` to say what's loading, such as "Loading requests".

## API

Selector: `mud-spinner`

<ArgTypes of={SpinnerStories} />

### Types

- `MudSpinnerSize`: `'xs' | 'sm' | 'md' | 'lg'`
- `MudSpinnerVariant`: `'brand' | 'dark' | 'light' | 'light-on-color'`
