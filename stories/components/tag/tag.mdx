# Tag

A small status label — approved, pending, rejected. Unlike a chip, a tag is not
interactive: it reports state rather than accepting input.

## Import

```ts
import { MudTag } from 'ngx-mud-ui/tag';

@Component({
  imports: [MudTag],
  template: `
    <mud-tag color="success">Approved</mud-tag>
    <mud-tag color="danger" type="strong" size="small">Rejected</mud-tag>
  `,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## Icons

A tag can show an icon before its label, after it, or both. Mark each icon with
`icon-start` or `icon-end`; the tag places it on that side, whatever order you
write it in.

```html
<mud-tag color="success"><mud-icon icon-start name="checkmark-small" [scale]="16" /> Approved</mud-tag>
<mud-tag color="brand">Details <mud-icon icon-end name="chevron-right-small" [scale]="16" /></mud-tag>
```

Each icon tightens only its own edge: 6px on a medium tag, 4px on a small one. The
icon renders at 16px on medium and 12px on small, so pass `[scale]="16"`.

## Disabled

Use `disabled` when the thing the tag labels is unavailable, such as a status inside a
disabled row. It replaces every `color` with the disabled grey, because a disabled tag
carries no state meaning. An `outlined` tag keeps its transparent fill and greys its
border and text.

```html
<mud-tag color="success" disabled>Approved</mud-tag>
```

The change is visual only. The tag adds no `aria-disabled`, so the disabled state must
be announced by the control or row that owns it.

## Usage tips

- **`aria-label` turns the tag into a live region.** Only when it is set does the
  tag become `role="status"` and announce changes; unlabelled tags stay silent,
  matching the official design system. Set it when the state can change while
  the user is on the page, leave it off for static labels.
- **A tag is not a chip.** Nothing here toggles or removes — reach for
  `mud-chip` when the user acts on it.
- **`type="strong"` is for the states that must not be missed**, such as a
  rejection; `subtle` is the default for routine statuses.
- **A tag never grows wider than its container.** A label that doesn't fit ends
  in "…"; with an icon, the label is cut at its end instead. Keep labels short:
  a status, not a sentence.
- **Colour is not the message.** `success` and `danger` read identically to a
  colourblind user, so the tag's text must say what the state is.
