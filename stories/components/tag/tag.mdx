# Tag

A small status label, such as approved, pending or rejected. A tag isn't interactive; for something
the user can toggle or remove, use a [Chip](?path=/docs/components-chip--docs).

```ts
import { MudTag } from 'ngx-mud-ui/tag';
```

## Colors and types

`color` is `neutral` (default), `muted`, `brand`, `info`, `success`, `accent` or `danger`. `type` is
`subtle` (default, tinted), `strong` (filled, for states nobody should miss) or `outlined`. `info`
has no `outlined` type and falls back to `subtle` with a dev-mode warning.

Color isn't the message: the text must say what the state is.

## Icons, sizes and disabled

Mark an icon with `icon-start` or `icon-end`; the tag places it on that side. Use `[scale]="16"` on a
`md` tag (default) and `[scale]="12"` on a `sm` one.

`disabled` greys the tag out whatever its color, for a status in a disabled row. It's visual only,
so the row or control must announce the state.

A tag never grows wider than its container: a label that doesn't fit ends in "…". Keep labels
short.

<Canvas of={TagStories.Icons} />

## Announcing changes

A tag is silent by default. With an `aria-label`, it becomes a polite live region
(`role="status"`) and changes to its text are announced. Set it when the status can change while
the user is on the page.

## API

Selector: `mud-tag`

<ArgTypes of={TagStories} />

Content slots: `[icon-start]`, the label and `[icon-end]`.

### Types

- `MudTagColor`: `'muted' | 'neutral' | 'accent' | 'success' | 'brand' | 'danger' | 'info'`
- `MudTagType`: `'subtle' | 'strong' | 'outlined'`
- `MudTagSize`: `'sm' | 'md'`
