# Icons

The `<mud-icon>` component renders every icon in the set. Each icon is a separate export, and only
the icons you register end up in your bundle.

```ts
import { MudIconComponent, provideMudIcons } from 'ngx-mud-ui/icons';
```

## Registering icons

Register the icons you use once, in `app.config.ts`, then use `<mud-icon>` anywhere:

```ts
import { alarm, arrowLeft, deleteIcon, provideMudIcons } from 'ngx-mud-ui/icons';

export const appConfig: ApplicationConfig = {
  providers: [provideMudIcons([alarm, arrowLeft, deleteIcon])],
};
```

You import an icon by its camelCase name (`arrowLeft`) and use it by its kebab-case `name`
(`name="arrow-left"`). `delete` is a reserved word in JavaScript, so its export is `deleteIcon`.
`name` is typed, so your editor autocompletes it and catches typos.

`provideMudIcons` works in any environment injector: the app config, or a lazy route's `providers`
to register icons when that route loads. Several calls add to one registry. It can't go in a
component's `providers`.

## Size and variant

`scale` is `12`, `16`, `20`, `24` (default) or `32`. Each size up to 24 has its own drawing; 32
scales up the 24 drawing, for empty states and highlights. `variant` is `outlined` (default) or
`filled`.

When an icon has no drawing at the requested size or variant, the nearest one is used. An
unregistered name renders nothing. Both log a warning in development.

## Color

Icons are drawn with `currentColor`, so they take the color of the surrounding text, inside
components too. To color an icon on its own, use the semantic `--mud-color-icon-*` tokens, which
also switch in dark mode. Avoid fixed hex colors.

## Accessibility

An icon is decorative by default (`aria-hidden="true"`), which is right next to visible text. When
the icon is the only content, as in an icon-only button, give it (or the button) an `aria-label`;
the icon then gets `role="img"`.

### Functions and types

- `provideMudIcons(icons: MudIcon[]): EnvironmentProviders`: registers icons.
- `MudIconRegistry`: the service behind it, with `register(icons)` and `get(name)`.
- `MudIconName`: the union of all icon names.
- `MudIconScale`: `12 | 16 | 20 | 24 | 32`
- `MudIconVariant`: `'outlined' | 'filled'`
