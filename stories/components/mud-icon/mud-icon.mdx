# Icon

One component renders every icon in the set. Icons are tree-shakeable: each is a
separate export, and only the ones you register are bundled.

## Import

Register the icons you use once at bootstrap, then use `mud-icon` anywhere:

```ts
// bootstrap
import { provideMudIcons, alarm, arrowLeft } from 'ngx-mud-ui/icons';

bootstrapApplication(App, {
  providers: [provideMudIcons([alarm, arrowLeft])],
});
```

```ts
// component
import { MudIconComponent } from 'ngx-mud-ui/icons';

@Component({
  imports: [MudIconComponent],
  template: `<mud-icon name="alarm" variant="outlined" [scale]="24" />`,
})
export class Demo {}
```

The base stylesheet must be in your app's `angular.json` `styles` once:

```json
"styles": ["node_modules/ngx-mud-ui/prebuilt/mud.css", "src/styles.scss"]
```

## Usage tips

- **Only registered icons render.** `provideMudIcons` is what pulls an icon into
  the bundle; a `name` you never registered resolves to nothing. That is the
  price of tree-shaking.
- **Icons are decorative by default.** With no `aria-label` the host is
  `aria-hidden`, which is correct beside a visible text label. Set `aria-label`
  only when the icon is the sole carrier of meaning.
- **The input is aliased `aria-label`**, so bind it as `[aria-label]="…"` in
  templates rather than by its class member name.
- **Color follows CSS `color`.** The glyph is drawn with `currentColor`, so it
  inherits from the surrounding text and adapts to the theme without extra work.
- **`scale` is a fixed rung** — 12, 16, 20, 24 or 32 — not an arbitrary pixel
  size, because the artwork is drawn per size rather than scaled. 32 is the
  exception: it has no artwork of its own and renders the 24 drawing scaled
  up, for feature callouts and empty states.
