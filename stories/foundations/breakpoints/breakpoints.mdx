# Breakpoints

Six min-width breakpoints from the official MUD grid, shipped from **`ngx-mud-ui/breakpoints`**
as Sass mixins and TypeScript constants. Both come from one source, so your stylesheets and
your code always agree.

Drag the slider or click a band to see which breakpoint is active and which mixins match:

<Canvas of={BreakpointStories.Explorer} />

## At a glance

- **Mobile first.** Every breakpoint is a *minimum* width. Write the small-screen style first,
  then add to it with `bp.up()`.
- **`md` (768px) is the main edge.** The library itself switches there: the type scale is smaller
  below it, `mud-sidebar-layout` stacks, and accordions use their compact layout. Use the same
  edge for your own mobile/desktop split so the page and the components change together.
- **`xs` (320px) is the floor.** Nothing is defined below it, so treat 320px as the smallest screen
  to design for.

## In stylesheets

```scss
@use 'ngx-mud-ui/breakpoints' as bp;
```

- **`bp.up(md)`** compiles to `(min-width: 768px)`. Adds to the mobile style on larger screens;
  the default choice.
- **`bp.down(md)`** compiles to `(max-width: 767.98px)`. Small-screen-only overrides; never overlaps
  `bp.up(md)`.
- **`bp.between(sm, lg)`** compiles to `(min-width: 576px) and (max-width: 991.98px)`. One range
  only: from the first breakpoint up to, not including, the second.

```scss
.page {
  padding: var(--mud-spacing-16);

  @include bp.up(md) {
    padding: var(--mud-spacing-32);
  }
}
```

The raw map is available as `bp.$breakpoints` if you need the values themselves.

## In TypeScript

`MudBreakpoints` holds the same min-width queries as strings, ready for the CDK
`BreakpointObserver`. `MudBreakpointValues` holds the pixel numbers.

```ts
import { BreakpointObserver } from '@angular/cdk/layout';
import { toSignal } from '@angular/core/rxjs-interop';
import { map } from 'rxjs';
import { MudBreakpoints, MudBreakpointValues } from 'ngx-mud-ui/breakpoints';

export class Shell {
  readonly isDesktop = toSignal(
    inject(BreakpointObserver).observe(MudBreakpoints.Md).pipe(map((state) => state.matches)),
  );
}

MudBreakpoints.Md;      // '(min-width: 768px)'
MudBreakpointValues.Md; // 768
```

Reach for TypeScript only when the *behavior* changes, such as rendering a different component or
closing a drawer. If only the look changes, a mixin is simpler and works before JavaScript runs.
